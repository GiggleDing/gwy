## 三、经济

### 基础概念

| 概念 | 含义 |
|---|---|
| GDP | 国内生产总值：一国境内在一定时期内生产的**最终产品和服务**的价值总和 |
| GNP | 国民生产总值：一国国民在国内外生产的最终产品和服务价值总和 |
| CPI | 消费者价格指数，衡量通货膨胀的主要指标 |
| PPI | 生产者价格指数 |
| 恩格尔系数 | 食品支出 ÷ 总消费支出。**越低说明越富裕** |
| 基尼系数 | 衡量收入分配差距。**0–1 之间，越大差距越大** |

::: tip 两个系数的方向不要搞反
- **恩格尔系数越低越好**（说明吃占的比重小）
- **基尼系数越小越平均**（0 是完全平均，1 是完全不平均）
:::

### 宏观调控

| 政策 | 工具 | 方向 |
|---|---|---|
| 财政政策 | 税收、政府支出、国债 | 经济过热→减支出、增税；经济下行→增支出、减税 |
| 货币政策 | 存款准备金率、利率、公开市场操作 | 经济过热→提高准备金率/利率；经济下行→降低 |

::: warning 一个高频方向判断题
**降准降息 = 宽松 = 刺激经济**（市场上钱变多）
**提准加息 = 紧缩 = 抑制通胀**（市场上钱变少）

题目常问"下列属于扩张性货币政策的是"，核心就是分辨方向。
:::

### 通货膨胀与通货紧缩

| 项 | 表现 | 对策 |
|---|---|---|
| 通货膨胀 | 物价持续上涨，货币贬值 | 紧缩政策；**对债权人不利，对债务人有利** |
| 通货紧缩 | 物价持续下跌 | 宽松政策 |

::: tip 记住一句话
**通胀时，借钱的人占便宜，存钱的人吃亏。** 因为还的钱购买力下降了。
:::

## 四、考场动作

1. 科技题遇到**当年的新进展** → 不知道就排除法，别恋战
2. 地理题优先用**常识直觉**判断，我国地理的基本格局是稳定的
3. 经济题看到**"越高越好/越低越好"** → 先判断是不是恩格尔/基尼这类方向性指标
4. 三科加起来**每次考试约 8–10 题**，每题 30 秒到线就走
