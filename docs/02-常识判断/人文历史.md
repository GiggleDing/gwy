## 一、文学常识

| 项 | 内容 |

### 各代代表

| 朝代 | 关键词 |
|---|---|
| 汉 | 司马迁《史记》——我国第一部**纪传体通史**；班固《汉书》——第一部**纪传体断代史** |
| 魏晋南北朝 | 陶渊明（田园诗）、王羲之《兰亭序》、刘勰《文心雕龙》 |

| 宋 | **宋词**：豪放派（苏轼、辛弃疾）、婉约派（柳永、李清照）；唐宋八大家中的宋六家：欧阳修、苏洵、苏轼、苏辙、王安石、曾巩 |
| 元 | **元曲**：关汉卿《窦娥冤》、王实甫《西厢记》 |
| 明清 | **四大名著**：《三国演义》（罗贯中）、《水浒传》（施耐庵）、《西游记》（吴承恩）、《红楼梦》（曹雪芹） |

::: tip 唐宋八大家
**唐二家**：韩愈、柳宗元
**宋六家**：欧阳修、苏洵、苏轼、苏辙、王安石、曾巩
口诀记"韩柳欧苏王曾"+"三苏"。
:::

### 二十四史与史书体例

| 体例 | 代表 | 特点 |
|---|---|---|
| 编年体 | 《春秋》《资治通鉴》 | 按年月日顺序记 |
| 纪传体 | 《史记》《汉书》 | 以人物为中心 |
| 国别体 | 《国语》《战国策》 | 按国家分 |

::: warning 最常考的一组
- 《史记》= **纪传体通史**
- 《资治通鉴》= **编年体通史**
- 《汉书》= **纪传体断代史**

三个"体例 + 通史/断代"的搭配必须一次记准。
:::

## 四、中国历史主线

| 时期 | 关键节点 |
|---|---|
| 夏商周 | 分封制、宗法制；西周→东周（春秋战国） |
| 秦 | 公元前 221 年统一，**我国第一个统一的中央集权封建王朝** |
| 汉 | 丝绸之路（张骞出使西域）、罢黜百家独尊儒术 |
| 隋唐 | 科举制（隋创立、唐完善）、贞观之治、开元盛世 |
| 宋元 | 经济重心南移完成、行省制度（元） |
| 明清 | 郑和下西洋、闭关锁国 |
| 近代 | 鸦片战争（1840）→ 辛亥革命（1911） |
| 现代 | 五四运动（1919）→ 建党（1921）→ 建国（1949） |

::: danger 几个高频年份
**1840** 鸦片战争 · **1911** 辛亥革命 · **1919** 五四运动 · **1921** 建党 · **1949** 建国 · **1978** 改革开放
:::

## 五、考场动作

1. 人文历史题**先看选项是否有明显错误**，通常能排除 2 项
2. 遇到"第一次/第一部/最早"的表述 → 优先怀疑，这类题目最爱在"最"字上设错
3. 完全陌生的内容 → 凭排除法选，**不纠结**
