# 法律常识

常识判断里**出题最多、最可系统学习**的板块。目标：把下面这些条文记得像乘法口诀一样熟。

## 一、宪法

### 基础事实

| 项 | 内容 |
|---|---|
| 现行宪法 | 1982 年颁布 |
| 修正次数 | **5 次**（1988、1993、1999、2004、2018） |
| 国家宪法日 | **12 月 4 日** |
| 宪法地位 | 国家的根本法，具有最高法律效力 |

### 国家机构

| 机构 | 性质 |
|---|---|
| 全国人民代表大会 | **最高国家权力机关** |
| 全国人大常委会 | 全国人大的常设机关 |
| 国家主席 | 国家元首 |
| 国务院 | **最高国家行政机关**，是最高国家权力机关的执行机关 |
| 中央军事委员会 | 领导全国武装力量 |
| 国家监察委员会 | **最高监察机关**（2018 年修宪新增） |
| 人民法院 | **审判机关** |
| 人民检察院 | **法律监督机关** |

::: tip 一句话区分
**人大是权力机关，国务院是行政机关，监委是监察机关，法院是审判机关，检察院是法律监督机关。**
题目的坑常把"法律监督机关"安到法院头上。
:::

### 公民基本权利

| 类别 | 内容 |
|---|---|
| 平等权 | 法律面前一律平等 |
| 政治权利和自由 | 选举与被选举权、言论出版集会结社游行示威自由、监督权 |
| 人身自由 | 人身自由、人格尊严、住宅不受侵犯、通信自由和通信秘密 |
| 宗教信仰自由 | |
| 社会经济权利 | 劳动权、休息权、财产权、物质帮助权 |
| 文化教育权利 | 受教育权、科学研究与文艺创作自由 |

::: warning 易错点
**"受教育"既是权利也是义务。** 题目常问"下列既属于权利又属于义务的是"，答案是受教育权和劳动权。
:::

## 二、民法典

2021 年 1 月 1 日施行，共 **7 编**：总则、物权、合同、人格权、婚姻家庭、继承、侵权责任。

### 民事行为能力

| 年龄 | 类型 |
|---|---|
| 不满 **8** 周岁 | 无民事行为能力人 |
| 满 **8** 周岁不满 **18** 周岁 | 限制民事行为能力人 |
| 满 **18** 周岁**以上** | 完全民事行为能力人 |
| 满 **16** 周岁、以自己劳动收入为主要生活来源 | **视为**完全民事行为能力人 |

::: danger 民事 vs 刑事的年龄完全不是一回事
- **民事**：8 岁 / 18 岁（16 岁劳动收入可视为完全）
- **刑事**：12 岁 / 14 岁 / 16 岁

两套数字必须分开记，题目的坑几乎全在这里。
:::

### 高频条文

| 项 | 内容 |
|---|---|
| 诉讼时效 | 一般 **3 年**，自权利人知道或应当知道权利受损害之日起算 |
| 离婚冷静期 | 申请之日起 **30 日**内，任何一方可撤回 |
| 遗嘱形式 | 自书、代书、打印、录音录像、口头、公证（共 6 种） |
| 法定继承第一顺序 | 配偶、子女、父母 |
| 法定继承第二顺序 | 兄弟姐妹、祖父母、外祖父母 |
| 人格权 | 生命权、身体权、健康权、姓名权、肖像权、名誉权、隐私权等 |

::: tip 继承顺序的记法
**第一顺序：配偶、子女、父母**（都是最亲近的直系关系）。
**第二顺序：兄弟姐妹、祖父母、外祖父母**。
丧偶儿媳/女婿对公婆/岳父母尽了主要赡养义务的，作为**第一顺序**继承人。
:::

## 三、刑法

### 刑事责任年龄

| 年龄 | 责任 |
|---|---|
| 不满 **12** 周岁 | 完全不负刑事责任 |
| 已满 **12** 不满 **14** 周岁 | 只对故意杀人、故意伤害罪，致人死亡或以特别残忍手段致人重伤造成严重残疾、情节恶劣，**经最高人民检察院核准追诉**的负责任 |
| 已满 **14** 不满 **16** 周岁 | 只对故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质罪负责任 |
| 已满 **16** 周岁 | 完全负刑事责任 |
| 已满 **75** 周岁 | 故意犯罪的，可以从轻或减轻处罚 |

::: warning 14–16 岁的八类罪要记全
**故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质** —— 共八类。
注意是"**贩卖**毒品"（不含吸食、持有），"**投放危险物质**"（不是"投毒"）。
:::

### 刑罚种类

| 类型 | 内容 |
|---|---|
| 主刑（5 种） | 管制、拘役、有期徒刑、无期徒刑、死刑 |
| 附加刑（4 种） | 罚金、剥夺政治权利、没收财产、驱逐出境 |

::: tip 主刑只能单独适用，附加刑可以附加适用也可以独立适用
题目常问"下列属于附加刑的是"，核心是把**罚金 vs 罚款**、**拘役 vs 拘留**分清：
- **罚金 / 拘役** → 刑事处罚
- **罚款 / 行政拘留** → 行政处罚
:::

### 正当防卫与紧急避险

| 项 | 要点 |
|---|---|
| 正当防卫 | 对**正在进行的不法侵害**，采取的制止行为，对侵害人造成损害不负刑责 |
| 防卫过当 | 明显超过必要限度造成**重大损害**的，应负刑责，但应减轻或免除处罚 |
| 特殊防卫 | 对正在进行**行凶、杀人、抢劫、强奸、绑架**等严重危及人身安全的暴力犯罪，造成侵害人伤亡的，**不属于防卫过当，不负刑责** |
| 紧急避险 | 为使自己或他人免受**正在发生的危险**，不得已损害另一较小合法权益的，不负刑责 |

::: danger 两个最常考的区分
1. **正当防卫 vs 紧急避险**：正当防卫针对的是**不法侵害人本人**；紧急避险损害的是**第三方的合法权益**。
2. **特殊防卫没有过当问题**：对行凶、杀人、抢劫、强奸、绑架这类暴力犯罪，怎么防都不算过当。
:::

## 四、行政法

### 行政处罚的种类（2021 年新法共 6 类）

1. 警告、通报批评
2. 罚款、没收违法所得、没收非法财物
3. 暂扣许可证件、降低资质等级、吊销许可证件
4. 限制开展生产经营活动、责令停产停业、责令关闭、限制从业
5. 行政拘留
6. 法律、行政法规规定的其他行政处罚

::: warning "通报批评"和"降低资质等级"是新增种类
这是 2021 年修订的亮点，也是常考的新增点。
:::

### 救济途径

| 途径 | 说明 |
|---|---|
| 行政复议 | 向**上一级行政机关或本级人民政府**申请 |
| 行政诉讼 | 向人民法院起诉 |
| 二者关系 | 一般可**自由选择**；法律规定复议前置的必须先复议 |

## 五、考场动作

1. 看到**年龄数字** → 立刻确认是民事还是刑事体系
2. 看到**"罚金/罚款""拘役/拘留"** → 确认是刑事还是行政
3. 看到**机构名称** → 核对性质（权力/行政/监察/审判/监督）
4. 看到**"不属于"** → 加重圈出，法律题最爱考选非

::: tip 这页怎么用
不要通读背诵。做法是：**每次做到法律类错题，回这一页找对应条目，把错的那一条圈起来。**
考前只看被圈过的条目。
:::
