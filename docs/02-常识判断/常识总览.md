# 常识判断 · 模块总览

**15 题。** 这是全卷最"不划算"的模块——知识面无限而题量有限，投入产出比最低。

> 因此策略只有一条：**只学可积累、可复现的部分，不赌运气，也不为它挤占其他模块的时间。**

## 一、定位与策略

| 项 | 说明 |
|---|---|
| 题量 | 15 题（三类卷相同） |
| 建议用时 | 8 分钟（单题 30 秒） |
| 目标正确率 | 55%（8/15） |
| 知识范围 | 法律、人文历史、科技、地理、经济、生活常识 |
| 时间投入 | **碎片时段**：每天 5 题，不占用整块时间 |

::: warning 为什么目标只有 55%
因为常识的知识面是没有边界的。**从 50% 提到 60% 需要的投入，远超把资料分析从 80% 提到 90% 所需。**
在只剩 70 天的前提下，把整块时间投给常识是明显的策略错误。
:::

### 投入优先级

| 优先级 | 板块 | 理由 |
|---|---|---|
| 高 | **法律** | 有明确条文，可积累、可复现，且是常识里出题最多的板块 |
| 中 | 时政类常识 | 与政治理论模块共用素材，一鱼两吃 |
| 中 | 科技生活 | 高频考点集中，可以背 |
| 低 | 人文历史 | 范围太广，性价比低，靠原有积累 |
| 低 | 地理国情 | 同上 |

::: tip 与政治理论联合备考
常识里的时政部分和政治理论模块**共享同一批素材**。学政治理论时顺手记一下常识能覆盖的点，不要在常识上重复投入。
:::

## 二、命题特点

| 特点 | 说明 |
|---|---|
| 学科融合 | 一道题可能同时涉及多个学科，考验综合应用 |
| 题干简短 | 通常 1–2 句话，信息量小，靠知识储备 |
| 选项迷惑性 | 干扰项常是"听起来合理"的错误说法 |
| 时政化倾向 | 越来越多题目以最新政策、事件为背景 |

::: info 一个变化值得注意
随着政治理论题量增加到 20 题，常识判断里**其他学科的题量相应减少**，而且与政治理论、时政的融合题增多。
这意味着**纯靠知识广度优势的题变少了，靠政策理解的题变多了**。
:::

## 三、答题策略

### 30 秒法则

读到题目的 30 秒内：
- **确定知道** → 直接选，走
- **有两个候选、拿不准** → 选第一直觉，标记但不回头
- **完全没见过** → 直接排除明显错误的，在剩余项里选最熟悉的

::: danger 常识题绝不回头
常识题的特点是"**再想也想不出来**"——它不像资料分析可以通过重算验证。
回头再看一遍，唯一的结果是又花掉 40 秒。
**在页面底部的时限内做决定，然后永不再看。**
:::

### 排除法的用法

常识题很少能正推，主要靠排除：

| 排除信号 | 说明 |
|---|---|
| 表述绝对化 | "必然""完全""所有""一定"——除非是公认结论 |
| 违背基础常识 | 与生活经验明显冲突 |
| 违背政策方向 | 与国家现行政策取向相反 |
| 逻辑不自洽 | 选项内部前后矛盾 |

::: warning 一个反复出现的坑
常识题的错误选项常写成**"政治正确但不符题意"**的样子——即选项本身说法没错，但不是题目问的那个知识点。
**先看清楚题目问的是什么，再看选项对不对。**
:::

## 五、每日最小动作

| 时段 | 动作 |
|---|---|
| 碎片时间 | 刷 5 题常识，**只记错题里的知识点**，不刷知识面 |
| 每周 | 把本周错题的知识点抄进 [错题归因表](/08-工具/错题归因表) |
| 考前两周 | 只过自己的错题清单，不新学 |

::: tip 一个务实的判断
如果时间紧张，常识可以**只做法律部分**。法律是唯一有明确边界、可系统学习的板块，其他板块的知识面投入产出比太低。
:::
