# 错题归因表

**归因的目的不是"记录错误"，是"找到可改进的动作"。**

## 一、通用归因四分类

每道错题**必须归到唯一一类**。归不进去，说明还没想清楚为什么错。

| 类型 | 特征 | 对应改进动作 |
|---|---|---|
| **知识盲区** | 考点完全没见过，或见过但忘了 | 回对应模块页补，进 [遗忘曲线排期](/08-工具/遗忘曲线排期) |
| **审题偏差** | 考点会，但看错了问法 | 提炼成"陷阱条目"记入本表 |
| **计算失误** | 方法对、式列对，算错 | 检查速算法使用是否规范 |
| **时间不够** | 没做或仓促蒙错 | 调整时间分配，不补知识 |

::: danger 最常见的误判
**把"审题偏差"当成"知识盲区"**，然后回去重学已经会的知识点——这是最浪费时间的错误。

**判断方法**：如果看完解析的第一反应是"哦原来问的是这个"，那就是审题问题，不是知识问题。
:::

::: danger 最后一栏最重要
**"什么时候这题不用算"比"用什么方法"更值钱。**
资料分析的核心能力不是算得快，是**识别出哪些题不需要算**。
:::

## 六、使用节奏

| 频率 | 动作 |
|---|---|
| 每次做题后 | 错题立即归因，填表 |
| 每周 | 汇总一次，更新"出现次数" |
| 每月 | 挑出出现 3 次以上的条目，做专项 |
| 考前两周 | **只看陷阱清单，不看新内容** |

::: tip 复盘的最终标准
复盘完能说出一句**具体**的话：
> "下次做资料分析，我先花 20 秒看 5 道题的题干，再读材料。"

如果只能说"我下次要更认真"，那这次复盘白做了。
:::
