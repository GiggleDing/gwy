# 遗忘曲线排期

**新知识学完记不住，不是记性问题，是复习间隔问题。**

## 一、复习间隔

<GkChart name="review-curve" />

每一轮具体做什么：

- **第 1 轮 · 学完 24 小时内** —— 合上材料，自己复述一遍核心结论
- **第 2 轮 · 学完第 3 天** —— 只看标记过的重点，做 5 道对应题
- **第 3 轮 · 学完第 7 天** —— 做题验证，错的地方重新标注
- **第 4 轮 · 学完第 15 天** —— 快速扫一遍，只扫标记过两次以上的
- **第 5 轮 · 学完第 30 天** —— 考前集中唤醒

::: tip 关键认知
**复习不是"再看一遍"，是"主动回想"。**
合上材料默写/复述，效果远好于重读。因为重读会产生"我已经会了"的错觉。
:::

## 二、怎么用这个节奏

### 学新知识当天

在笔记顶部写三个日期：

```
学习日：10/05
第 1 轮：10/06  ✓
第 2 轮：10/08
第 3 轮：10/12
第 4 轮：10/20
第 5 轮：11/04
```

每完成一轮就打个勾。**没打勾的会一直提醒你。**

### 碎片时段怎么用

| 时段 | 用途 |
|---|---|
| 早上 | 当天该复习的内容（按上面的日期表） |
| 通勤 | 政治理论/常识的题 |
| 睡前 | 快速过一遍当天的标记点 |

::: warning 不要做的事
**不要"今天有时间，就把所有该复习的都过一遍"。**
一次过太多，等于没复习。**每天只处理"今天到期"的那一批。**
:::

## 三、哪些内容需要排期

| 内容类型 | 是否需要排期 | 说明 |
|---|---|---|
| 方法卡（如速算五法） | **需要** | 容易忘，且忘了直接掉分 |
| 公式（如平均数增长率） | **需要** | 高频错误点 |
| 政治理论标准表述 | **需要** | 记忆量大，最容易忘 |
| 常识知识点 | 需要 | 但优先级最低 |
| 成语/实词辨析 | **需要** | 靠反复见 |
| 行测战略（做题顺序等） | 不需要 | 属于习惯，练成就不会忘 |

::: danger 最该排期的是"高频错误点"
复习的优先级不是按内容重要度排，而是按**你出错频率**排。
**错三次以上的知识点，必须进排期表。**
:::

## 四、与现有排期表的配合

工作区里已有一份 `复习排期_遗忘曲线.csv`，本页的节奏与它保持一致。

::: tip 使用建议
1. 学完一个新模块，当天就在 CSV 里加一行
2. 每天早上扫一眼今天到期的条目
3. **完成就打勾，未完成就顺延到第二天**（不要跳过）
:::

## 五、考前两周的特殊处理

| 时间 | 做法 |
|---|---|
| 考前 14 天 | 停止学新知识，只做复习 |
| 考前 7 天 | 只复习**标记过两次以上**的内容 |
| 考前 3 天 | 过一遍 [错题归因表](/08-工具/错题归因表) 里的陷阱清单 |
| 考前一天 | 只看最核心的公式和战略，**不碰新内容** |

::: danger 考前翻新内容只有坏处
考前看到没学过的内容，会产生焦虑，但不会有任何转化。
**这个阶段的唯一任务是"唤醒"，不是"重建"。**
:::

## 六、一个必须接受的现实

::: tip 忘掉是正常的
按上面的节奏走，仍然会有内容在考场上想不起来——**这是正常的，不需要因此调整方法。**
真正的问题不是"忘了多少"，而是**"高频错误点有没有被反复固化"**。

**把注意力放在"错过的题不要再错"，而不是"所有知识都记住"。**
:::
