# 逻辑判断

**10 题，单题上限 70 秒。** 核心：**翻译题靠背规则，加强削弱题靠找论点。**

## 一、题型分布

| 题型 | 题量（约） | 方法 |
|---|---|---|
| 翻译推理 | 3–4 | 背规则，直接套 |
| 加强/削弱 | 3–4 | 找论点、比力度 |
| 前提假设 | 1 | 搭桥 |
| 真假推理 | 1 | 找矛盾 |
| 日常结论 | 1 | 排除法 |

---

## 二、翻译推理（必背）

### 四组翻译规则

| 关联词 | 翻译方向 |
|---|---|
| **如果 A，那么 B** / 只要 A，就 B / 若 A 则 B | **A → B**（前推后） |
| **只有 A，才 B** | **B → A**（后推前） |
| **除非 A，否则 B** | **-A → B** |
| 不 A 不 B | **B → A** |

::: danger 最容易错的一组
**"如果…那么…"是前推后，"只有…才…"是后推前。**

记法：
- "如果 A 那么 B" → A 是 B 的**充分条件** → A→B
- "只有 A 才 B" → A 是 B 的**必要条件** → B→A

**"只有…才…"是唯一需要反向的，特别标记。**
:::

### 逆否等价（核心工具）

```
A → B  等价于  -B → -A
```

::: tip 这是翻译推理最常用的动作
已知 A→B，且知道 -B，就能推出 -A。
**注意：-A 推不出任何东西，B 也推不出任何东西。**
:::

### 递推

```
A → B，B → C  ⟹  A → C
```

### 且、或

| 关系 | 真值 | 否定 |
|---|---|---|
| $A \wedge B$（且） | 全真才真 | $\neg(A \wedge B) = \neg A \vee \neg B$ |
| $A \vee B$（或） | 全假才假 | $\neg(A \vee B) = \neg A \wedge \neg B$ |

::: warning 德摩根定律
**否定"且"变"或"，否定"或"变"且"。**
这一条在选项判断里极常用。
:::

### 考场动作

1. 看到"如果/只有/除非/否则" → **立刻翻译成箭头，写在题目旁边**
2. 从**确定的信息**出发，顺着箭头推
3. 选项与自己推出的结论不符 → 直接排除
4. **不要用"读起来通不通顺"来判断**

## 三、真假推理

### 矛盾关系（必有一真一假）

| 命题 A | 矛盾命题 |
|---|---|
| 所有都是 | **有的是非** |
| 所有都不是 | **有的是** |
| 某个是 | 某个非 |

### 反对关系

| 关系 | 真假规律 |
|---|---|
| "所有是" 与 "所有非" | **必有一假**（可同假） |
| "有的是" 与 "有的非" | **必有一真**（可同真） |

### 解题三步

```
第 1 步  找矛盾关系（必有一真一假）
第 2 步  看其余（题目说只有一真，则其余全假）
第 3 步  回代验证
```

## 四、加强 / 削弱题（题量最多）

### 第一步：找论点

**论点通常在**：因此、所以、可见、据此、研究表明、认为 之后。

::: danger 找错论点 = 必错
**论点是作者要证明的结论，论据是支撑结论的理由。**
很多人的错误动作是"针对论据来削弱"——那不是最强削弱。
:::

### 削弱力度排序（从强到弱）

| 力度 | 方法 | 说明 |
|---|---|---|
| **最强** | **否定论点** | 直接说结论不成立 |
| 次强 | **拆桥** | 切断论据与论点之间的联系 |
| 较弱 | **否定论据** | 说论据是错的 |
| 最弱 | **另有他因** | 提出还有其他原因，但不否定原论据 |

### 加强力度排序（从强到弱）

| 力度 | 方法 | 说明 |
|---|---|---|
| **最强** | **搭桥** | 建立论据与论点之间的联系 |
| 次强 | **解释说明** | 解释为什么论点成立 |
| 较弱 | **举例子** | 举一个支持论点的例子 |

::: tip 最实用的判断
**加强题优选"搭桥"**（把论据和论点连起来）。
**削弱题优选"否定论点"**（直接说结论错）。
拿到题先看有没有这两类选项。
:::

### 前提假设型

问法："上述论证基于以下哪项假设"

**方法**：**搭桥** —— 找出论据和论点之间缺的那一环。

::: tip 判断标准
把选项**否定**一下，如果否定后整个论证不成立了，那它就是必要的前提。
这个方法叫"否定代入法"，非常有效。
:::

## 五、日常结论型

问法："由此可以推出"

### 三不选

| 不选 | 说明 |
|---|---|
| 表述绝对的 | "必然""一定""全部" |
| 无中生有的 | 材料里没提的 |
| 偷换概念的 | 概念被替换的 |

::: tip 选择顺序
1. 先排除绝对化表述
2. 再排除无中生有
3. 剩下的选最保守、最"弱"的那个

**日常结论题里，越保守的表述越可能是答案。**
:::

## 六、考场动作

| 题型 | 单题上限 | 关键动作 |
|---|---|---|
| 翻译推理 | 60 秒 | 立刻翻译成箭头 |
| 真假推理 | 70 秒 | 找矛盾 |
| 加强削弱 | 70 秒 | 先圈论点 |
| 前提假设 | 60 秒 | 否定代入法 |
| 日常结论 | 50 秒 | 排除绝对化 |

::: danger 逻辑判断题最忌"哲学思辨"
**不要用现实世界的合理性来判断选项**，要用题目给出的逻辑关系。
题干说"所有的乌鸦都是白的"，你就当它是真的，不要因为现实中乌鸦是黑的就否定它。
**这是逻辑判断题失分的一个隐蔽原因。**
:::
