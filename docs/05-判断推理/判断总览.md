# 判断推理 · 模块总览

**35 题，全卷题量最大的模块，占 25.9%。** 规律数量有限、边界清晰，是**仅次于资料分析的提分模块**。

> 你已经过一遍、正确率约 80%。这一页的任务是**把规律固化成"看到就知道查哪一类"的条件反射**，以及**限时**。

## 二、四大题型的核心方法

| 题型 | 一句话方法 |
|---|---|
| 图形推理 | **按元素组成分流**：相同看位置、相似看样式、不同看属性再看数量 |
| 定义判断 | **抓关键词**：主体、客体、方式、目的、结果，违背一个即排除 |
| 类比推理 | **先定一级关系，再比二级辨析** |
| 逻辑判断 | **翻译记规则，加强削弱找论点** |

## 三、通用提速原则

### 定义判断：不做通读

::: warning 最常见的时间浪费
把定义从头读到尾，全部理解了再看选项。
**正确做法**：扫一眼定义，立刻圈出关键词，然后直接去选项里对照。
:::

### 类比推理：不信"感觉最像"

必须能说出**是什么关系**。说不出关系的选择，就是赌。

### 图形推理：试三种规律就跳

::: danger 50 秒规则
**试过 3 种规律仍无思路，立即标记跳过。**
图形推理的"没思路"往往是真的没思路，再盯 2 分钟也不会想出来。
这 2 分钟挪给后面任何一道题都比留在这里强。
:::

### 逻辑判断：翻译题不靠理解

翻译推理是**纯规则题**，背熟公式直接套，不要靠"读起来通不通顺"。

::: tip 复盘重点
判断推理的错题，要区分是**"规律不知道"**还是**"知道规律但没试到"**：
- 前者 → 补进本模块页面
- 后者 → 这是**规律检索顺序**的问题，要固定一套检查顺序

**绝大多数错题属于后者**，说明问题不在于知识，而在于没有一套稳定的"排查顺序"。
:::
