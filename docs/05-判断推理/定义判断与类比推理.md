# 定义判断与类比推理

两个题型放在一起，因为它们的共同点：**方法固定、耗时短、是判断推理里最稳定的得分点。**

---

# 第一部分：定义判断（10 题）

## 一、核心方法：关键词法

::: danger 不要通读定义
把定义从头读到尾、全部理解了再看选项——这是最常见的时间浪费。
**正确动作**：扫一眼定义，立刻圈出关键词，然后直接去选项里对照。
:::

## 二、五类关键词

| 关键词 | 说明 | 例 |
|---|---|---|
| **主体** | 动作的发出者 | "行政机关"、"企业"、"自然人" |
| **客体** | 动作的接受者 | "对……实施"、"向……提供" |
| **目的** | 行为的动机 | "为了……"、"旨在……" |
| **方式/手段** | 通过什么手段 | "通过……方式"、"以……名义" |
| **结果/条件** | 产生什么后果 | "导致……"、"在……情况下" |

::: tip 做题顺序
**主体优先。** 大部分错误选项都是主体不对——比如定义说的是"行政机关"，选项主体是企业，直接排除。
:::

## 三、选项排除法

| 步骤 | 动作 |
|---|---|
| 1 | 圈出题干关键词（主体、客体、方式、目的、结果） |
| 2 | 逐项对照，**违背任一关键词即排除** |
| 3 | 若还剩两项，比较**哪个与关键词匹配度更高** |
| 4 | 不在细节上纠结 |

::: warning 两个高频失分点
1. **没看清"属于"还是"不属于"** —— 定义判断题最爱在这上面设坑，务必圈出
2. **在"边缘选项"上耗时太久** —— 两个选项都像时，选匹配更多关键词的那个，然后走
:::

## 四、定义判断的常见定义领域

| 领域 | 说明 |
|---|---|
| 社会学 | 社会现象、社会关系 |
| 心理学 | 心理现象、认知偏差 |
| 修辞学 | 修辞手法 |
| 生物学 | 生物现象、生态关系 |
| 统计学 | 统计概念 |
| 经济学 | 经济现象、管理概念 |
| 法律 | 法律概念（与常识判断交叉） |

::: tip 不要被名词吓到
定义判断题**不考你知不知道这个概念**，只考你会不会对照关键词。
题干里已经给了完整定义，**你完全不需要有背景知识**。
:::

# 第二部分：类比推理（10 题）

## 一、做题顺序

```
第 1 步  造句子 / 定关系  →  明确两个词是什么关系
第 2 步  一级辨析        →  逻辑关系 > 言语关系 > 语法关系
第 3 步  二级辨析        →  若一级关系相同，再比细分
```

::: danger 最核心的纪律
**必须能说出"是什么关系"。**
说不出关系、只凭"感觉最像"来选，就是赌。**这是类比推理失分的唯一原因。**
:::

## 二、一级关系：逻辑关系

| 关系 | 说明 | 例 |
|---|---|---|
| **全同** | 两个词意思完全相同 | 麦克风 : 话筒 |
| **并列—矛盾** | 非此即彼，无第三种 | 生 : 死 |
| **并列—反对** | 除两者外还有别的 | 苹果 : 梨 |
| **包容—种属** | A 是 B 的一种 | 苹果 : 水果 |
| **包容—组成** | A 是 B 的一部分 | 轮胎 : 汽车 |
| **交叉** | 有重合但不完全包含 | 教师 : 党员 |
| **对应** | 功能、材料、因果、场所、时间等 | 钢笔 : 写字 |

::: warning 种属 vs 组成 —— 最高频的坑
- **种属**："苹果是一种水果" —— 后面能加"一种"
- **组成**："轮胎是汽车的一部分" —— 不能说"轮胎是一种汽车"

**判定口诀：能加"是一种"的，是种属。**
:::

## 三、一级关系：言语关系

| 关系 | 说明 |
|---|---|
| 近义 | 意义相近 |
| 反义 | 意义相反 |
| 比喻象征 | 如"松柏 : 坚贞" |
| 感情色彩 | 褒义 / 贬义 / 中性 |

## 四、一级关系：语法关系

| 关系 | 说明 | 例 |
|---|---|---|
| 主谓 | 主语 + 谓语 | 阳光 : 明媚 |
| 动宾 | 动词 + 宾语 | 学习 : 知识 |
| 偏正 | 修饰语 + 中心语 | 红色 : 花朵 |

## 五、二级辨析（一级关系相同时才用）

| 角度 | 说明 |
|---|---|
| 必然 vs 或然 | 一定会发生 vs 可能发生 |
| 人工 vs 自然 | 人造物 vs 自然物 |
| 主要 vs 次要 | 主要功能 vs 次要功能 |
| 直接 vs 间接 | 直接对应 vs 间接对应 |
| 抽象 vs 具体 | 概念 vs 实物 |
| 顺序 | 时间先后、因果关系方向 |

::: tip 二级辨析的使用时机
**只有当两个选项的"一级关系"都成立时，才需要用到二级辨析。**
大部分题目走到一级关系就能定答案。
:::

## 六、考场动作

| 步骤 | 时长 |
|---|---|
| 定关系 | 10 秒 |
| 比对选项 | 15 秒 |
| 超时 | 30 秒 → 选最像的，走 |

::: danger 类比推理是最不该超时的题型
它只有 30 秒的预算。**在一道类比题上纠结 1 分钟，等于白送两道题的时间。**
说不出关系就凭第一感觉选，标记但不回头。
:::

## 七、每日动作

| 题型 | 题量 | 目的 |
|---|---|---|
| 定义判断 | 10 题 | 练"圈关键词"的速度 |
| 类比推理 | 15 题 | 保持关系判断的手感 |

::: tip 错题怎么记
类比推理的错题，只记一件事：**"我漏掉了哪个二级辨析角度"**。
积累一段时间后，你会发现自己的盲区很集中（通常是"必然 vs 或然"和"主要 vs 次要"），针对性补就行了。
:::
