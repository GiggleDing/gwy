# 图形推理

**10 题，单题上限 50 秒。** 核心不是"想到规律"，而是**有一套固定的排查顺序**，避免东试一个西试一个。

## 一、第一动作：看元素组成

::: tip 这是全部方法的总开关
拿到图形后，**第一个动作不是想规律，是判断"元素组成"属于哪一类**：

```
元素组成相同  →  看位置（平移、旋转、翻转）
元素组成相似  →  看样式（遍历、加减同异）
元素组成不同  →  先看属性（对称、曲直、开闭）
                属性没规律 → 再看数量（点、线、角、面、素）
                数量也没规律 → 看特殊规律（笔画数、部分数）
```
:::

**按这个顺序走，不要跳步。** 跳步是图形推理失分和超时的主要原因。

## 二、位置类（元素相同）

| 规律 | 说明 |
|---|---|
| **平移** | 元素在行/列/圆周上移动，注意**方向、步数、是否循环** |
| **旋转** | 顺时针或逆时针，注意**角度**（45°、90°、135°、180°） |
| **翻转** | 水平翻转（左右镜像）或垂直翻转（上下镜像） |

::: warning 平移题的三要素
判断平移必须同时看三点：**方向、步数、边界处理（循环还是反弹）**。
只看出方向就选，是常见的失分点。
:::

::: tip 黑白块是近年高频
"黑白块"题现在常考**运算**（黑+黑=白之类），不只是平移。
看到黑白块先试平移，平移不通立刻试**黑白的叠加运算**。
:::

## 三、样式类（元素相似）

| 规律 | 说明 |
|---|---|
| **遍历** | 每行/每列出现相同的元素集合，缺哪个补哪个 |
| **直接叠加** | 前两图直接合成第三图 |
| **去同存异** | 前两图相同的部分去掉，不同的留下 |
| **去异存同** | 前两图不同的部分去掉，相同的留下 |
| **规律叠加** | 按特定规则运算（如黑+白=黑） |

## 四、属性类（元素不同，先看这里）

| 属性 | 细分 |
|---|---|
| **对称性** | 轴对称、中心对称、轴对称+中心对称 |
| **曲直性** | 全直线、全曲线、直线+曲线 |
| **开闭性** | 全封闭、全开放、半开半闭 |

::: danger 对称性是国考每年的必考点
判断对称要注意三件事：
1. **对称类型**（轴对称 / 中心对称 / 两者都是）
2. **对称轴的方向**（横、竖、斜）
3. **对称轴的数量**（1 条 / 2 条 / 多条）

**只判断"是不是对称"是不够的**，近年题目大多在对称轴的**方向或数量**上做区分。
:::

## 五、数量类（属性无规律时）

| 元素 | 常见考法 |
|---|---|
| **点** | 交点、端点、切点、十字交叉点 |
| **线** | 直线数、曲线数、线条总数、笔画数 |
| **角** | 直角数、锐角数、钝角数、角的总数 |
| **面** | 封闭区域数（最常考） |
| **素** | 元素种类数、元素个数 |

::: tip 快速判断该数什么
| 图形特征 | 优先数 |
|---|---|
| 封闭区域多（"窟窿多"） | **面** |
| 线条交叉多 | **点** |
| 全由直线/曲线构成 | **线** |
| 有多个小图形散落 | **素** |
| 出现直角、明显的角 | **角** |
:::

## 六、特殊规律（数量也无规律时）

### 笔画数（考频极高）

::: tip 一笔画判定法则
**奇点数为 0 或 2 的连通图形，可以一笔画成。**

**奇点** = 从该点引出的线条数为**奇数**的点。
:::

### 特征图速查

| 看到什么 | 想什么规律 |
|---|---|
| "日"字变形、"田"字变形 | **笔画数** |
| 五角星、圆内接多边形 | **笔画数 / 线条数** |
| 生活化图形（如笑脸、电话） | **部分数** |
| 黑色粗线条图形 | **部分数** |
| 汉字 | 笔画数、结构、部分数、封闭区域 |
| 字母 | 笔画数、曲直性、封闭区域 |

::: danger 最强的一个信号
**"日"和"田"的变形图出现 → 几乎可以直接锁定笔画数。**
这是图形推理里最可靠的"特征图"对应关系。
:::

## 七、空间类

| 题型 | 方法 |
|---|---|
| **六面体折叠** | 找相对面（同行/同列隔一个）、找相邻面（看公共边） |
| **三视图** | 主视图、俯视图、左视图，注意遮挡关系 |
| **截面图** | 判断能否切出某形状 |
| **立体拼合** | 数小方块数量、看凹凸互补 |

::: tip 六面体折叠的核心
**相对面不能同时出现**——这一条能排除大部分错误选项。
再结合"相邻面的公共边是否吻合"就能锁定答案。
:::

## 八、考场动作（固定顺序）

```
第 1 步（5 秒）  看元素组成 → 相同 / 相似 / 不同
第 2 步（20 秒） 按对应规律试
第 3 步（25 秒） 换下一个类别试
                 ├─ 试到 3 种规律都没思路
                 └─ 立即标记跳过（50 秒规则）
```

::: danger 不要做的事
1. **不要把同一类规律试到底**（比如数面数不出，就以为题目难，其实该数点了）
2. **不要因为"图形难看"就放弃** —— 图形难看往往意味着规律简单（比如对称）
3. **不要在一道题上超过 50 秒** —— 10 道题 8 分钟，平均每题只有 48 秒
:::

## 九、限时训练怎么做

| 方式 | 说明 |
|---|---|
| 每天 10 题 | **严格计时**，每题 50 秒，到点就跳 |
| 记录项 | 每题试了几种规律、哪种规律命中 |
| 目标 | 试到命中的平均次数 ≤ 2 次 |

::: tip 练的是什么
图形推理练的不是"见过多少规律"，而是**"多快能试到正确的那个规律"**。
限定时间刷题，比不限时刷题有用得多。
:::
