# 速算五法

**目标：把单题平均用时从 90 秒压到 45 秒。**

::: tip 一个前置认知
资料分析 90% 的题**不需要精算**，只需要在选项里选出对的。
**"算得准"不是目标，"选得对"才是目标。**
:::

---

## 一、截位直除法（最常用，适用所有除法）

### 原理

除法计算时，分子分母同时截取前 2–3 位有效数字，忽略后面的位数。

### 截取规则（按选项差距定）

| 选项差距 | 截位位数 | 例子 |
|---|---|---|
| **大**（选项首位不同，或差距 $> 10\%$） | 截 **2 位** | 选项 12、23、35、48 |
| **小**（首位相同，或差距 $< 10\%$） | 截 **3 位** | 选项 123、128、131、136 |
| 极小（差距 $< 5\%$） | 截 4 位或直接精算 | |

### 两种用法

| 用法 | 说明 | 精度 |
|---|---|---|
| **只截分母，分子不截** | 更精确，推荐 | 高 |
| 分子分母都截 | 更快，但要注意量级 | 中 |

### 例

**求** $\dfrac{54321}{1.078} \approx ?$

- 分母截 3 位 → 108
- $\dfrac{54321}{108} \approx 503$
- 对照选项（48500 / 50400 / 52100 / 53800），选 50400
- 用时：15 秒（精算需 60 秒以上）

::: tip 最高效的一招
**先看选项首位。** 如果选项首位都不同（如 23、35、48），只需要算到商的第一位就锁定答案了。
:::

## 二、特征数字法（百化分）

### 必背百化分表

| 分数 | 百分数 | 分数 | 百分数 |
|---|---|---|---|
| 1/2 | 50% | 1/9 | 11.1% |
| 1/3 | 33.3% | 1/11 | 9.1% |
| 2/3 | 66.7% | 1/12 | 8.3% |
| 1/4 | 25% | 1/13 | 7.7% |
| 3/4 | 75% | 1/14 | 7.1% |
| 1/5 | 20% | 1/15 | 6.7% |
| 1/6 | 16.7% | 1/16 | 6.25% |
| 1/7 | 14.3% | 1/17 | 5.9% |
| 2/7 | 28.6% | 1/18 | 5.6% |
| 3/7 | 42.9% | 1/19 | 5.3% |
| 1/8 | 12.5% | 1/20 | 5% |
| 3/8 | 37.5% | 2/9 | 22.2% |

### 三种应用场景

| 场景 | 用法 |
|---|---|
| **求增长量** | $r \approx \frac{1}{n}$ 时，$\text{增长量} \approx \dfrac{\text{现期量}}{n + 1}$ |
| **求基期量** | $r \approx \frac{1}{n}$ 时，$\text{基期量} \approx \dfrac{\text{现期量} \times n}{n + 1}$ |
| **乘法近似** | $A \times 14.3\% \approx \dfrac{A}{7}$ |

### 例

**求** 某值 8960，同比增长 $14.3\%$，增长了多少？

- $14.3\% \approx \dfrac{1}{7}$ → 用 n+1 法
- $\text{增长量} \approx \dfrac{8960}{8} = 1120$
- 用时：10 秒（精算需 90 秒以上）

::: danger 必须先判断 r 是否接近某个 1/n
**只有当 $r$ 与表中某个 $\frac{1}{n}$ 的误差在 1 个百分点以内时才能用。**
$r = 14.3\%$ 用 $\frac{1}{7}$ 是精确的；$r = 15.8\%$ 强行用 $\frac{1}{7}$ 就会出错。
:::

## 三、有效数字法（乘法）

### 取舍规则

| 情况 | 做法 |
|---|---|
| 两乘数第三位都 $\le 2$ | **全舍**，取前 2 位 |
| 两乘数第三位都 $\ge 8$ | **全进**，前 2 位各 $+1$ |
| 其他情况 | **一进一舍**：前 2 位小的四舍五入，大的反向变化 |

::: tip 结合选项定精度
选项差距大 → 取前 2 位；选项差距小 → 取前 3 位。
**注意量级要单独判断**，有效数字法只算有效数字。
:::

## 四、同位比较法（比较大小，不算具体值）

### 适用场景

**比较多个分数的大小**（增长率比较、比重比较、平均数比较）。

### 比较规则

| 情况 | 判断 |
|---|---|
| 分子大、分母小 | **直接判定分数大** |
| 分子大、分母也大 | 比较**增长幅度**：分子涨得比分母快 → 分数大 |

::: tip 最关键的应用
**比较增长率大小，等价于比较 $\dfrac{\text{现期量}}{\text{基期量}}$ 的大小。**
因为 $\text{增长率} = \dfrac{\text{现期量}}{\text{基期量}} - 1$，减 1 不影响大小关系。

所以**根本不用算出每个增长率**，只需要比较分数大小。
:::

### 例

比较三个市 GDP 增长率（现期 / 基期）：

- A 市：$\dfrac{3456}{3200} \approx 1.080$
- B 市：$\dfrac{5678}{5100} \approx 1.113$
- C 市：$\dfrac{2345}{2100} \approx 1.117$
- → **C 市最高**
- 用时：25 秒（分别精算需 90 秒）

## 五、尾数法（加减法专用）

### 使用条件（三个都要满足）

1. **选项尾数各不相同**
2. 题目是**精确的加减法**，不是估算题
3. 数据精度与选项一致

### 用法

| 运算 | 说明 |
|---|---|
| 加法 | 只加末位数字 |
| 减法 | 注意借位 |
| 加减混合 | 按顺序算，注意每步借位 |

::: warning 尾数相同的处理
如果末位有相同的，就算**后两位**。
:::

## 六、五法适用场景对照

| 方法 | 适用 | 关键动作 |
|---|---|---|
| **截位直除** | 所有除法（基期、比重、平均数、倍数） | 先看选项定截位位数 |
| **特征数字法** | 增长率接近 $\frac{1}{n}$ 的乘除法 | 先查是不是接近 $\frac{1}{n}$ |
| **有效数字法** | 乘法计算 | 判断取舍规则 |
| **同位比较法** | 分数大小比较 | 只看大小，不算值 |
| **尾数法** | 加减法 | 确认选项尾数不同 |

::: tip 使用顺序
**先判断题型 → 再选方法 → 不是先选方法再套题。**

看到"求基期"→ 截位直除；看到"$r \approx 14.3\%$"→ 特征数字；看到"哪个最大"→ 同位比较。
**方法是被题型召唤出来的，不是主动去找题的。**
:::

## 七、什么时候完全不用算

**这是本页最重要的一节。**

| 场景 | 判定 |
|---|---|
| 比重变化方向 | $a > b \Rightarrow$ 上升；$a < b \Rightarrow$ 下降。**不用算** |
| 比重变化量 | 一定小于 $\lvert a - b \rvert$（百分点）。**先筛选项再算** |
| 增长率比较 | 比较 $\dfrac{\text{现期量}}{\text{基期量}}$ 的大小即可。**不用算具体值** |
| 平均数比较 | 同位比较。**不用算具体值** |
| 尾数不同的加减 | 只算尾数 |
| 混合增长率 | 介于各部分之间，偏向基数大的一方。**不用算** |

::: danger 方法卡里必须写的那一栏
每次归纳方法，都写一栏 **"什么时候这题不用算"**。

**这一栏比"用什么公式"更值钱。** 因为它直接决定了你能不能在 28 分钟里做完 20 题。
:::
