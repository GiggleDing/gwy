# 资料分析 · 模块总览

**20 题（4 篇材料 × 5 题），建议用时 28 分钟。**

> **这是全卷唯一"只要学了就能拿分"的模块。** 目标正确率 85%，是行测分数的基本盘。

## 一、为什么这个模块最重要

| 项 | 数据 |
|---|---|
| 题量 | 20 题 |
| 高频考点集中度 | 增长、比重、平均数合计占比 **超 80%** |
| 计算难度 | 近年显著降低，无复杂运算 |
| 选项设计 | 适配估算，截位直除即可解题 |
| 提分速度 | 系统训练 1 个月可提 5–8 分 |

::: tip 三个必须记住的判断
1. **资料分析是行测里唯一可以做到 90% 正确率的模块**
2. **它不考智力，考规范**——方法对了就是对的
3. **它是耗时最大的模块，也是最容易被"想省时间"而做错的模块**

**在这个模块上投入的时间，回报率高于任何其他模块。**
:::

## 二、近年命题变化（重要）

| 变化 | 影响 |
|---|---|
| 综合分析题从 4 题锐减至 **2 题** | 大幅减少耗时 |
| 综合分析的**正确选项多分布在前两项** | 降低验证成本 |
| 简单计算与比较题重回考查，占比约 15% | 快速得分点 |
| 材料内容聚焦国家战略领域 | 可能带注释说明，需快速理解陌生统计概念 |
| 命题陷阱更具针对性 | 集中于累计/当期混淆、单位换算、统计口径差异 |

::: warning 两个高频易错点已被点名
**两期比重差** 和 **增长率混合问题** —— 这两个是现在的高频易错点，本模块页面里单独讲。
:::

## 三、目标正确率分解

| 题型 | 题量 | 目标 |
|---|---|---|
| 现期量 / 增长率 基础计算 | 约 6 | 6/6 |
| 基期量计算 | 约 4 | 4/4 |
| 增长量计算 | 约 3 | 3/3 |
| 比重计算与比较 | 约 4 | 3/4 |
| 平均数 / 倍数 | 约 2 | 2/2 |
| 综合分析 | 2 | 1/2 |
| **合计** | **20** | **17–19** |

## 四、时间分配

| 阶段 | 用时 |
|---|---|
| 每篇材料读题干 + 定位数据 | 每篇约 6–7 分钟 |
| 单题上限 | 90 秒 |
| 综合分析题 | 可放宽到 100 秒，但**只做 2 题** |
| 检查 | 不单独留时间，靠做的时候仔细 |

::: danger 资料分析最贵的错误
**"这道题我再算精确一点"** —— 资料分析不需要精确，只需要在选项里选出对的。
**截位直除能解决的问题，不要用精算。**
:::

## 五、做题的固定流程

```
第 1 步  看问题（不是看材料）
        └─ 圈出：时间 / 主体 / 考点
第 2 步  回材料定位数据
第 3 步  列式
第 4 步  速算（按选项差距选择截位位数）
第 5 步  选最接近的选项
```

::: tip 为什么"先看问题"
先通读材料再做题，有两个问题：
1. **材料里的数据记不住**，做题时还要回头找
2. **不知道要找什么**，读的时候没有重点

**先看问题、圈关键词、再回材料定位**——这是唯一高效的流程。
:::

## 七、每日最小动作

| 动作 | 量 |
|---|---|
| 每日刷题 | 20 题（4 篇材料），限时 **28 分钟** |
| 计时分两段 | **识别用时** + **计算用时**分开记 |
| 学新方法时 | 用约 70% 的题**不限时**精做，归纳方法 |
| 验证方法时 | 用预留的约 30% 题**限时**做 |
| 归纳重点 | **不是"怎么算得快"，是"哪些题不用算"** |

::: tip 这套流程的关键
**把"识别用时"和"计算用时"分开记**，能暴露一个关键问题：
你是**找不到数据**，还是**算得太慢**？

两者是完全不同的问题——前者要靠熟悉材料结构，后者要靠速算法。**不分清就没法针对性改进。**
:::

## 八、一个必须建立的意识

> **资料分析的核心能力不是"算得快"，而是"判断哪些题不用算"。**

| 不用算的题 | 判断依据 |
|---|---|
| 比重变化方向 | 部分增速 > 整体增速 → 比重上升，不用算 |
| 比重变化量 | 一定小于 \|部分增速 - 整体增速\| 这个差值（百分点） |
| 增长率比较 | 比较现期/基期的大小即可，不用算具体值 |
| 平均数比较 | 同位比较法，不用算出具体值 |
| 尾数不同的加减法 | 只算尾数 |

::: danger 方法卡里最该记的一栏
每次归纳方法，都要写一栏：**"什么时候这题不用算"。**
这一栏比"用什么公式"更值钱。
:::
