# 核心概念与公式

**符号约定**（全页统一）：

| 符号 | 含义 |
|---|---|
| 现期量 / 基期量 | 当期数值 / 上一期数值 |
| $r$ | 增长率 |
| $A$ / $a$ | **部分**的现期量 / 部分增长率 |
| $B$ / $b$ | **整体**的现期量 / 整体增长率 |

---

## 一、增长类（占比约 30%）

### 基础四公式

$$
\begin{aligned}
r &= \frac{\text{现期量} - \text{基期量}}{\text{基期量}} = \frac{\text{增长量}}{\text{基期量}} \\[6pt]
\text{现期量} &= \text{基期量} \times (1 + r) \\[6pt]
\text{基期量} &= \frac{\text{现期量}}{1 + r} \\[6pt]
\text{增长量} &= \text{现期量} - \text{基期量} = \text{基期量} \times r = \frac{\text{现期量} \times r}{1 + r}
\end{aligned}
$$

::: tip 最常用的两个变形
- 求基期：$\text{基期量} = \dfrac{\text{现期量}}{1 + r}$
- 求增长量：$\text{增长量} = \dfrac{\text{现期量}}{1 + r} \times r$（当 $r \approx \dfrac{1}{n}$ 时，可用"n+1 法"秒算）

**"n+1 法"**：若 $r \approx \dfrac{1}{n}$，则 $\text{增长量} \approx \dfrac{\text{现期量}}{n + 1}$。
例：$r = 14.3\% \approx \dfrac{1}{7}$ → 增长量 $\approx \dfrac{\text{现期量}}{8}$。
:::

### 间隔增长率

$$
r_{\text{间隔}} = r_1 + r_2 + r_1 r_2
$$

::: tip 速算技巧
当 $r_1$ 和 $r_2$ **都小于 10%** 时，$r_1 r_2$ 可以忽略：
$r \approx r_1 + r_2$
:::

### 混合增长率（高频易错点）

::: danger 这是被点名的易错点
**整体增长率一定介于各部分增长率之间，且偏向基数大的那一方。**

例：$A$ 部分增长 $10\%$，$B$ 部分增长 $20\%$，则整体增长率在 $10\% \sim 20\%$ 之间。
如果 $A$ 的量远大于 $B$，则整体增长率更接近 $10\%$。
:::

### 年均增长率

$$
\text{末期量} = \text{初期量} \times (1 + r)^n \qquad (n \text{ 为年份差})
$$

::: warning 三个必须注意的点
1. **$n$ 是年份差**，不是年份数。2019 年到 2023 年，$n = 4$
2. 不是简单的算术平均，**不能用 $\dfrac{\text{末期量} - \text{初期量}}{\text{初期量} \times n}$**
3. 考题中常给"年均增长率约为多少"，可以代入选项验证
:::

## 二、比重类（占比约 35%，最高频）

### 现期比重

$$
\text{现期比重} = \frac{\text{部分}}{\text{整体}} = \frac{A}{B}
$$

### 基期比重

$$
\text{基期比重} = \frac{A}{B} \times \frac{1 + b}{1 + a}
$$

::: warning 公式位置不能搞反
**分子是 $(1 + b)$，分母是 $(1 + a)$** —— 即"整体增长率 + 1"在上，"部分增长率 + 1"在下。

记法：$\text{基期比重} = \text{现期比重} \times \dfrac{1 + b}{1 + a}$。
**"整体在上"**，因为 $\text{比重} = \dfrac{\text{部分}}{\text{整体}}$，分子的增长率在分母。
:::

### 比重变化判断（不用算！）

::: tip 一行判断，直接秒杀
$$
\begin{aligned}
a > b &\;\Rightarrow\; \text{比重上升} \\[4pt]
a < b &\;\Rightarrow\; \text{比重下降} \\[4pt]
a = b &\;\Rightarrow\; \text{比重不变}
\end{aligned}
$$

**记法**：部分涨得比整体快，说明它在整体里的占比自然提高。
:::

### 比重变化量

$$
\text{比重变化量} = \text{现期比重} - \text{基期比重} = \frac{A}{B} \times \frac{a - b}{1 + a}
$$

::: danger 不用精算的秒杀规律
**比重变化量一定小于 $\lvert a - b \rvert$ 这个差值（单位：百分点）。**

如果选项里只有一个小于 $\lvert a - b \rvert$，直接选它，**完全不用算**。
这是本模块最高效的一条规律。
:::

::: warning 百分数 vs 百分点
- **增长率本身**比较用"百分数"（增长率是 $8\%$）
- **增长率之间的差**用"百分点"（增长率提高了 3 个百分点）

题目问"比重变化了几个百分点"——**单位是百分点**。
:::

## 三、平均数类（占比约 15%）

### 现期平均数

$$
\text{现期平均数} = \frac{\text{总量}}{\text{总份数}} = \frac{A}{B}
$$

### 基期平均数

$$
\text{基期平均数} = \frac{A}{B} \times \frac{1 + b}{1 + a}
$$

**（与基期比重公式完全相同，$A$ = 总量，$B$ = 份数）**

### 平均数增长率（考频极高，必须背熟）

$$
\text{平均数增长率} = \frac{a - b}{1 + b}
$$

其中 **$a$ = 总量的增长率，$b$ = 份数的增长率**。

::: danger 这个公式最容易被记错
$$\text{平均数增长率} = \frac{a - b}{1 + b}$$

- 分子是 **$a - b$**（总量增速减份数增速）
- 分母是 **$1 + b$**（是**份数**的增长率，不是总量的！）

很多人记成 $\dfrac{a - b}{1 + a}$，这是最高频的公式错误。
**记不住就现推：$\text{平均数} = \dfrac{A}{B}$，用"平均数增长率 $= \dfrac{A\text{增速} - B\text{增速}}{1 + B\text{增速}}$"。**
:::

## 四、倍数类

| 问法 | 公式 |
|---|---|
| A 是 B 的几倍 | $A \div B$ |
| A 比 B 多几倍 | $A \div B - 1$ |
| A 超过 B 多少倍 | $A \div B - 1$ |

::: warning 最常见的低级失误
**"是几倍"和"多几倍"差 1。**

题目问"今年产量比去年多几倍"，答案是 $\dfrac{\text{现期量}}{\text{基期量}} - 1$，不是 $\dfrac{\text{现期量}}{\text{基期量}}$。
这属于审题问题，一旦看错，方法再对也白搭。
:::

## 五、公式速查汇总

| 求什么 | 公式 | 能否秒杀 |
|---|---|---|
| 基期量 | $\dfrac{\text{现期量}}{1 + r}$ | 截位直除 |
| 增长量 | $\dfrac{\text{现期量}}{1 + r} \times r$ | $r \approx \frac{1}{n}$ 时用 n+1 法 |
| 间隔增长率 | $r_1 + r_2 + r_1 r_2$ | 都小于 10% 时近似相加 |
| 混合增长率 | 介于各部分之间，偏向基数大的一方 | **不用算** |
| 现期比重 | $\dfrac{A}{B}$ | 截位直除 |
| 基期比重 | $\dfrac{A}{B} \times \dfrac{1 + b}{1 + a}$ | 判断与现期比重的大小关系 |
| 比重变化方向 | $a$ 与 $b$ 比较 | **完全不用算** |
| 比重变化量 | $\dfrac{A}{B} \times \dfrac{a - b}{1 + a}$ | **一定小于 $\lvert a - b \rvert$** |
| 现期平均数 | $\dfrac{A}{B}$ | |
| 基期平均数 | $\dfrac{A}{B} \times \dfrac{1 + b}{1 + a}$ | |
| 平均数增长率 | $\dfrac{a - b}{1 + b}$ | 直接算，数字通常不大 |
| 是几倍 | $A \div B$ | |
| 多几倍 | $A \div B - 1$ | |

::: tip 每次归纳方法卡，都要填这一栏
**"什么时候这题不用算"。**

上表里已经标出了 4 处"不用算"的场景——**这 4 处覆盖了相当比例的题量**，认出来就直接省掉一分钟。
:::
