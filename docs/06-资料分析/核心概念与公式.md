# 核心概念与公式

**符号约定**（全页统一）：

| 符号 | 含义 |
|---|---|
| 现期量 / 基期量 | 当期数值 / 上一期数值 |
| r | 增长率 |
| **A / a** | **部分**的现期量 / 部分增长率 |
| **B / b** | **整体**的现期量 / 整体增长率 |

---

## 一、增长类（占比约 30%）

### 基础四公式

```
增长率 r = (现期 - 基期) ÷ 基期 = 增长量 ÷ 基期
现期 = 基期 × (1 + r)
基期 = 现期 ÷ (1 + r)
增长量 = 现期 - 基期 = 基期 × r = 现期 × r ÷ (1 + r)
```

::: tip 最常用的两个变形
- 求基期：**基期 = 现期 ÷ (1 + r)**
- 求增长量：**增长量 = 现期 ÷ (1 + r) × r**（当 r ≈ 1/n 时，可用"n+1 法"秒算）

**"n+1 法"**：若 r ≈ 1/n，则 增长量 ≈ 现期 ÷ (n + 1)。
例：r = 14.3% ≈ 1/7 → 增长量 ≈ 现期 ÷ 8。
:::

### 间隔增长率

```
间隔增长率 r = r₁ + r₂ + r₁ × r₂
```

::: tip 速算技巧
当 r₁ 和 r₂ **都小于 10%** 时，r₁ × r₂ 可以忽略：
**r ≈ r₁ + r₂**
:::

### 混合增长率（高频易错点）

::: danger 这是被点名的易错点
**整体增长率一定介于各部分增长率之间，且偏向基数大的那一方。**

例：A 部分增长 10%，B 部分增长 20%，则整体增长率在 10%–20% 之间。
如果 A 的量远大于 B，则整体增长率更接近 10%。
:::

### 年均增长率

```
末期量 = 初期量 × (1 + r)^n     （n 为年份差）
```

::: warning 三个必须注意的点
1. **n 是年份差**，不是年份数。2019 年到 2023 年，n = 4
2. 不是简单的算术平均，**不能用 (末期 - 初期) ÷ 初期 ÷ n**
3. 考题中常给"年均增长率约为多少"，可以代入选项验证
:::

## 二、比重类（占比约 35%，最高频）

### 现期比重

```
现期比重 = 部分 ÷ 整体 = A ÷ B
```

### 基期比重

```
基期比重 = (A ÷ B) × (1 + b) ÷ (1 + a)
```

::: warning 公式位置不能搞反
**分子是 (1 + b)，分母是 (1 + a)** —— 即"整体增长率 + 1"在上，"部分增长率 + 1"在下。

记法：基期比重 = 现期比重 × [(1+整体)/(1+部分)]。
**"整体在上"**，因为比重 = 部分/整体，分子的增长率在分母。
:::

### 比重变化判断（不用算！）

::: tip 一行判断，直接秒杀
```
部分增长率 a > 整体增长率 b  →  比重上升
部分增长率 a < 整体增长率 b  →  比重下降
部分增长率 a = 整体增长率 b  →  比重不变
```

**记法**：部分涨得比整体快，说明它在整体里的占比自然提高。
:::

### 比重变化量

```
比重变化量 = 现期比重 - 基期比重
          = (A ÷ B) × (a - b) ÷ (1 + a)
```

::: danger 不用精算的秒杀规律
**比重变化量一定小于 |a - b| 这个差值（单位：百分点）。**

如果选项里只有一个小于 |a - b|，直接选它，**完全不用算**。
这是本模块最高效的一条规律。
:::

::: warning 百分数 vs 百分点
- **增长率本身**比较用"百分数"（增长率是 8%）
- **增长率之间的差**用"百分点"（增长率提高了 3 个百分点）

题目问"比重变化了几个百分点"——**单位是百分点**。
:::

## 三、平均数类（占比约 15%）

### 现期平均数

```
现期平均数 = 总量 ÷ 总份数 = A ÷ B
```

### 基期平均数

```
基期平均数 = (A ÷ B) × (1 + b) ÷ (1 + a)
```

**（与基期比重公式完全相同，A = 总量，B = 份数）**

### 平均数增长率（考频极高，必须背熟）

```
平均数增长率 = (a - b) ÷ (1 + b)
```

其中 **a = 总量的增长率，b = 份数的增长率**。

::: danger 这个公式最容易被记错
**平均数增长率 = (a - b) / (1 + b)**

- 分子是 **a - b**（总量增速减份数增速）
- 分母是 **1 + b**（是**份数**的增长率，不是总量的！）

很多人记成 (a-b)/(1+a)，这是最高频的公式错误。
**记不住就现推：平均数 = A/B，用"平均数增长率 = (A增速 - B增速)/(1 + B增速)"。**
:::

## 四、倍数类

| 问法 | 公式 |
|---|---|
| A 是 B 的几倍 | **A ÷ B** |
| A 比 B 多几倍 | **A ÷ B - 1** |
| A 超过 B 多少倍 | A ÷ B - 1 |

::: warning 最常见的低级失误
**"是几倍"和"多几倍"差 1。**

题目问"今年产量比去年多几倍"，答案是 现期/基期 - 1，不是 现期/基期。
这属于审题问题，一旦看错，方法再对也白搭。
:::

## 五、公式速查汇总

| 求什么 | 公式 | 能否秒杀 |
|---|---|---|
| 基期量 | 现期 ÷ (1 + r) | 截位直除 |
| 增长量 | 现期 ÷ (1 + r) × r | r ≈ 1/n 时用 n+1 法 |
| 间隔增长率 | r₁ + r₂ + r₁r₂ | 都小于 10% 时近似相加 |
| 混合增长率 | 介于各部分之间，偏向基数大的一方 | **不用算** |
| 现期比重 | A ÷ B | 截位直除 |
| 基期比重 | (A÷B) × (1+b)/(1+a) | 判断与现期比重的大小关系 |
| 比重变化方向 | a 与 b 比较 | **完全不用算** |
| 比重变化量 | (A÷B) × (a-b)/(1+a) | **一定小于 \|a-b\|** |
| 现期平均数 | A ÷ B | |
| 基期平均数 | (A÷B) × (1+b)/(1+a) | |
| 平均数增长率 | (a-b) ÷ (1+b) | 直接算，数字通常不大 |
| 是几倍 | A ÷ B | |
| 多几倍 | A ÷ B - 1 | |

::: tip 每次归纳方法卡，都要填这一栏
**"什么时候这题不用算"。**

上表里已经标出了 4 处"不用算"的场景——**这 4 处覆盖了相当比例的题量**，认出来就直接省掉一分钟。
:::
