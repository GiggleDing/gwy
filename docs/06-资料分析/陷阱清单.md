# 陷阱清单

资料分析的错题，**绝大多数不是算错，是看错**。这一页按"审题动作"组织，做完每道题对照检查。

## 一、时间类陷阱

### 陷阱 1：同比 vs 环比

| 概念 | 基期是谁 |
|---|---|
| **同比** | 上年**同期** |
| **环比** | **上一个统计周期**（上月 / 上季度） |

::: danger 看错一次就是一题
题目问"同比增长"时，基期是**去年同月/同期**；问"环比增长"时，基期是**上个月**。
**圈出"同比"还是"环比"，这一秒是必花的。**
:::

### 陷阱 2：时间范围看错

| 类型 | 说明 |
|---|---|
| **累计 vs 当期** | "1–6 月累计"和"6 月当月"是完全不同的数 |
| 年份看错 | 材料给了多年数据，题目问的是特定某年 |
| 区间看错 | "2019–2023 年"和"2023 年"不同 |

::: warning 累计与当期混淆已被点名为高频陷阱
材料里同时给出"累计值"和"当期值"时，**必须在题干上圈出问的是哪个**。
这类题的错误率异常高，因为两个数据都在材料里，随便抓一个就能算出"看起来很合理"的错误答案。
:::

## 二、概念类陷阱

### 陷阱 3：增长率 vs 增长量

| 问法 | 求什么 |
|---|---|
| 增长**最快** / 增幅最大 | **增长率**（相对数，%） |
| 增长**最多** / 增量最大 | **增长量**（绝对数） |

::: danger "最快"和"最多"是两个完全不同的问题
- 一个规模很小的项目，增长率可以很高（增长最快）
- 一个规模很大的项目，增长量可以很大但增长率不高（增长最多）

**这两个词看错，方向就全错了。**
:::

### 陷阱 4：百分点 vs 百分数

| 表述 | 含义 |
|---|---|
| 增长率**提高了 3%** | 增长率本身再涨 3% |
| 增长率**提高了 3 个百分点** | 增长率从 X% 变成 (X+3)% |

::: tip 记住一句话
**两个百分数相减，单位是"百分点"。**
题目问"比重变化了多少"——答案单位一定是百分点。
:::

### 陷阱 5：是几倍 vs 多几倍

```
A 是 B 的几倍  = A ÷ B
A 比 B 多几倍  = A ÷ B - 1
```

::: warning 一个字的差别
题目说"比…多几倍"时，答案要**减 1**。
这是纯粹的审题问题，方法再熟也救不回来。
:::

## 三、范围类陷阱

### 陷阱 6：整体范围看错

| 类型 | 说明 |
|---|---|
| "占全国的比重" vs "占全省的比重" | 整体不同，结果完全不同 |
| "出口额" vs "进出口总额" | 范围不同 |
| "规模以上企业" vs "全部企业" | 统计口径不同 |

::: danger 统计口径差异已被点名
**材料里的"某类"和题干问的"某类"可能不是同一范围。**
题干出现限定词时（如"规模以上"、"限额以上"、"国有控股"），回材料确认口径是否一致。
:::

## 四、单位类陷阱

### 陷阱 7：单位换算

| 常见坑 | 换算 |
|---|---|
| 亿 / 万 | 1 亿 = 10000 万 |
| 元 / 万元 | 1 万元 = 10000 元 |
| 吨 / 万吨 | 1 万吨 = 10000 吨 |
| % / ‰ | 1% = 10‰ |
| 公顷 / 亩 | 1 公顷 = 15 亩 |
| 平方千米 / 公顷 | 1 km² = 100 公顷 |

::: tip 最实用的一个动作
**计算前先统一单位，写在草稿上。**
"亿元"和"万元"混算，结果会差 10000 倍——但选项里往往真有一个差 10000 倍的错误答案在等你。
:::

## 五、审题动作清单

**每道题做完前，花 3 秒过一遍这几条：**

| 检查项 | 动作 |
|---|---|
| 1. 时间 | 圈出问的是哪一年 |
| 2. 同比/环比 | 圈出基期 |
| 3. 问的是什么 | 增长率还是增长量？是几倍还是多几倍？ |
| 4. 整体是谁 | 回材料确认分母 |
| 5. 单位 | 确认前后单位一致 |
| 6. 口径 | 有无"规模以上"这类限定词 |

::: danger 这 3 秒是全卷性价比最高的一段时间
资料分析 90% 的错题不是算错，是**看错**。
花 3 秒做这 6 项检查，能挡掉大部分非计算类失误。
:::

## 六、错题归因表（资料分析专用）

每道错题填一行：

| 日期 | 题号 | 错因类型 | 具体原因 | 改进动作 |
|---|---|---|---|---|
| | | 时间类 / 概念类 / 范围类 / 单位类 / 计算类 / 定位失败 | | |

::: tip 归因的意义
连续记两周后你会看到：**你的错误集中在哪一类**。
- 集中在**时间类** → 圈关键词的动作没养成
- 集中在**计算类** → 速算法没练熟
- 集中在**定位失败** → 不熟悉材料结构，需要练"先看问题再定位"

**不同原因对应完全不同的改进动作。不归因，就永远在同一个地方摔跤。**
:::
