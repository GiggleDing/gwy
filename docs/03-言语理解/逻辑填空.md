# 逻辑填空

**15 题，言语模块里题量最大、规律性最强的部分。**

核心结论只有一句：**逻辑填空考的是"对应关系"，不是"哪个词更好听"。**

## 一、固定三步法

```
第 1 步  不看选项    →  根据语境自己预判一个词
第 2 步  找对应点    →  判断是哪种关系（转折/并列/递进/解释）
第 3 步  才看选项    →  用辨析六角度逐项筛
```

::: danger 最常见的错误动作
拿到题直接看选项，然后"读一遍哪个顺"。这个动作一旦形成习惯，正确率会长期卡在 60–70%。
**强制自己先预判**，坚持两周就会形成新的条件反射。
:::

## 二、四种对应关系

### 1. 反对关系（填反义或相对义）

**信号词**：

| 类型 | 词 |
|---|---|
| 转折词 | 但是、然而、却、反而、其实、事实上、不过、固然…但是 |
| 对照词 | 不是…而是、过去…现在、要…不能、表面…实际 |
| 否定词 | 不、没有、并非 |

::: tip 动作
看到转折词 → 空格处与**转折词前的意思相反或相对**。
:::

### 2. 并列关系（填近义或同向义）

**信号词**：

| 类型 | 词 |
|---|---|
| 并列连词 | 和、与、及、以及、同时、也、又 |
| 并列结构 | 分号、顿号连接的并列短语 |
| 正反并列 | 不是…而是、既…又、一方面…另一方面 |

::: tip 动作
并列结构里，**空格处与并列项的语义方向一致**（同向并列）或**相反**（反义并列）。
注意区分是"同向"还是"反向"。
:::

### 3. 递进关系（填语意更重的词）

**信号词**：甚至、更、乃至、进而、不仅…而且、不但…还

::: tip 动作
递进后的词**语意比前面更重、程度更深**。选项里语意更重的那个对。
:::

### 4. 解释说明关系（填与解释内容一致的词）

**信号词**：即、就是、可以说、换言之、也就是说、冒号、破折号

::: tip 动作
空格前后是**互相解释**的关系，语义必须一致。这类题往往最容易做对——因为线索就在原文里。
:::

::: warning 判断顺序
四类关系里，**先找解释说明和反对关系**（最明确），再找并列和递进。
如果四处都找不到信号词，说明这道题的线索可能藏在**分句之间的语义逻辑**里，需要整体理解——这时候果断标记跳过，别耗。
:::

## 三、词语辨析六角度

锁定语义方向后，用这六个角度在剩余选项里筛：

| 角度 | 说明 | 例 |
|---|---|---|
| **含义侧重** | 词义的重点不同 | "遏制"侧重制止过程，"遏止"侧重使之停止 |
| **语义轻重** | 程度深浅不同 | "轻视" < "蔑视" < "仇视" |
| **感情色彩** | 褒/中/贬 | "果断"（褒）vs "武断"（贬） |
| **搭配对象** | 固定搭配不同 | "颁布"配法令，"颁发"配奖状 |
| **适用范围** | 适用对象不同 | "抚养"对晚辈，"赡养"对长辈 |
| **词性句法** | 词性不同，语法位置不同 | 名词/动词/形容词的位置要求 |

::: tip 六角度的使用顺序
**先用"含义侧重 + 感情色彩"筛掉 2 个，再用"搭配对象"定最后答案。**
绝大多数题走到第二步就出结果了。
:::

## 四、高频成语辨析对照

### 最常考的区别组

| 组 | 区别 |
|---|---|
| 一蹴而就 / 一挥而就 | 前者指事情轻易成功（多用于否定），后者指写字作画快 |
| 望洋兴叹 / 望而却步 | 前者因力量不够而感叹，后者因害怕而退缩 |
| 应运而生 / 水到渠成 | 前者顺应时机产生，后者条件成熟自然成功 |
| 南辕北辙 / 背道而驰 | 前者强调行动与目的相反，后者强调方向完全相反 |
| 同日而语 / 相提并论 | 前者多用于否定（不可同日而语），指不能相比 |
| 寥寥无几 / 凤毛麟角 | 前者形容数量少，后者形容稀少而珍贵 |
| 耳濡目染 / 耳熟能详 | 前者强调受影响，后者强调听得多了很熟悉 |
| 不以为然 / 不以为意 | 前者不认为是正确的，后者不放在心上 |
| 无所不为 / 无所不至 | 前者什么坏事都干（贬），后者指坏事做绝或关怀备至 |
| 鱼龙混杂 / 鱼目混珠 | 前者成分复杂好坏都有，后者以假充真 |
| 首当其冲 / 一马当先 | 前者最先受冲击（不是"冲在前面"），后者带头领先 |
| 差强人意 / 不尽人意 | 前者大体上还能让人满意（褒义倾向），后者不能让人满意 |

::: danger "首当其冲"和"差强人意"是被误用最多的两个
- **首当其冲** = 最先受到攻击或遭遇灾难，**不是**"冲在最前面"
- **差强人意** = 大体上还能使人满意，**不是**"不能让人满意"

这两个词国考反复考，必须一次记准。
:::

### 高频实词辨析

| 组 | 区别 |
|---|---|
| 厘清 / 理清 | "厘清"用于界限、关系；"理清"用于思路、头绪 |
| 遏制 / 遏止 | "遏制"是控制住（如遏制反弹）；"遏止"是使之停止 |
| 权利 / 权力 | "权利"是公民的权益；"权力"是政治上的强制力 |
| 启事 / 启示 | "启事"是公告文体；"启示"是启发提示 |
| 汇合 / 会合 | "汇合"用于水流；"会合"用于人员 |
| 流传 / 留传 | "流传"是传播开；"留传"是遗留下来传给后代 |

## 五、考场动作

1. **第一步永远是预判**，不看选项
2. 找到对应关系后，**把关系类型写在题号旁边**（转折/并列/递进/解释）
3. 45 秒到线 → 标记跳过
4. 两个选项犹豫时 → 回到"搭配对象"这个最客观的角度判断
5. **不要因为"读起来不顺"就换答案** —— "不顺"不是理由

::: tip 复盘标准
逻辑填空的错题，必须能回答：**这道题我错在哪一步？**
- 预判就错了 → 语义方向没抓对
- 预判对、选的选项错 → 词义辨析不够，记进成语表
- 完全没看懂句子 → 这是阅读理解问题，不是方法问题

分不清错在哪一步，就等于没复盘。
:::
