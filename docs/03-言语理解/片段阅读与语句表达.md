# 片段阅读与语句表达

## 一、片段阅读总原则

**先看问法定题型，再读文段找答案。**

::: warning 常见错误动作
先通读文段、理解了内容，再看问什么。
这个顺序的问题是：**读完你记住了内容，但不知道题目要你选什么**，于是又读一遍。
**先看问法**，然后带着目标读，一次就够。
:::

## 二、主旨概括题

**问法**：主要说明、旨在强调、核心观点是、这段文字主要介绍

### 两个抓手

#### 抓手一：主题词

文段中**高频出现的名词**就是主题词。

::: tip 用法
选项里**没有出现主题词的，直接排除**。这一步能筛掉大部分错误选项。
:::

#### 抓手二：行文脉络

| 结构 | 特征 | 主旨位置 |
|---|---|---|
| 总—分 | 先给观点，后举例论证 | **开头** |
| 分—总 | 先分析，后给结论 | **结尾** |
| 总—分—总 | 提观点—论证—再总结 | 首尾 |
| 并列 | 几个方面地位相当 | **需要自己归纳** |

::: tip 找主旨的最快方法：找关联词
**转折词之后是重点**（但是、然而、其实、事实上）
**结论词之后是重点**（因此、所以、可见、总之）
**对策词之后是重点**（应该、必须、需要、亟需）
:::

### 主旨题的错误选项特征

| 类型 | 说明 |
|---|---|
| 无中生有 | 文段没提过的内容 |
| 扩大范围 | 把"部分"说成"全部" |
| 偷换主体 | 把 A 做的事安到 B 上 |
| 偏离重点 | 只覆盖了非重点部分 |
| 过于具体 | 只说了文段的一个细节 |

## 三、意图判断题

**问法**：意在说明、想表达、作者想强调

::: danger 最集中的失分点
**如果文段是在"提出问题"，答案通常是对策，不是对问题的概括。**

例：文段讲"某地水资源浪费严重，原因是……"
- 错误选项：概括浪费现象
- 正确选项：提出解决浪费的对策

**看到"意在"，先找对策句；找不到对策句，才回到主旨。**
:::

### 判断口诀

| 文段类型 | 选什么 |
|---|---|
| 提出问题 | 选对策 |
| 提出对策 | 选对策本身 |
| 说明现象 | 选对现象的合理推断 |
| 讲道理 | 选道理背后的启示 |

## 四、细节判断题

**问法**：符合/不符合文意、可以推出/不能推出

### 方法

::: tip 唯一正确的方法
**逐项回原文核对**，不要试图通读理解。
每读一个选项，回原文找到对应句子，比对是否一致。
:::

### 四种常见设错

| 类型 | 手法 |
|---|---|
| 偷换概念 | 把相近但不同的概念互换 |
| 无中生有 | 编造原文没有的内容 |
| 绝对化 | 把"可能"说成"必然"、"部分"说成"全部" |
| 混淆条件 | 把充分条件说成必要条件 |

::: warning 细节题的耗时陷阱
细节题是最费时的题型（选项要逐项核对）。**单题超过 70 秒就标记跳过**，做完其他题再回来。
它不值得吃掉后面简单题的时间。
:::

## 五、标题填入题

**方法**：兼具**概括性**和**吸引力**。

| 错误类型 | 特征 |
|---|---|
| 过于宽泛 | 放之四海而皆准，没抓到具体话题 |
| 过于具体 | 只覆盖了文段的一个细节 |
| 偏离主题 | 抓错了主题词 |

::: tip 判断标准
好标题 = **主题词 + 概括角度**。先筛掉没有主题词的，再在剩下的里选最概括的那个。
:::

## 六、下文推断题

**问法**：作者接下来最有可能讲的是

### 方法

1. **找尾句话题** —— 下文必然承接尾句
2. **排除已讲过的内容** —— 文段讲过的不会再讲
3. **排除跨越式内容** —— 逻辑上不可能直接跳到

::: tip 最快的判断
**尾句是"提出问题"，下文就是"分析原因"或"给出对策"。**
**尾句是"提出概念"，下文就是"解释概念"。**
:::

## 七、语句排序题

**题量只有 2–3 题，掌握下面两点就够。**

### 第一步：找首句

| 适合作首句 | 不适合作首句 |
|---|---|
| 背景引入 | 指代词开头（这、那、其、该） |
| 下定义 | 关联词后半部分（但是、因此、而且） |
| 提出观点 | 补充说明性语句 |

### 第二步：找绑定

| 绑定类型 | 说明 |
|---|---|
| 指代绑定 | 指代词和它指代的内容必须相邻 |
| 关联词绑定 | "因为…所以""虽然…但是"必须配套相邻 |
| 话题绑定 | 讲同一话题的句子倾向连在一起 |
| 时间顺序 | 按时间先后排列 |
| 逻辑顺序 | 总分、因果、递进 |

::: tip 不要硬排全部顺序
用"首句排除 + 绑定排除"两步，通常能直接锁定答案。
**试图把 5 句话全部排清楚，是浪费时间。**
:::

## 八、语句填空题

**方法**：看空格位置

| 位置 | 作用 |
|---|---|
| 段首 | 总起，统领下文 |
| 段中 | 承上启下，需同时照应前后 |
| 段尾 | 总结，收束全文 |

::: warning 段中空格的常见错误
只看了前半句就选，忽略了后半句的要求。
**段中空格必须同时满足前后两个方向的语义要求。**
:::

## 九、考场动作总结

| 题型 | 单题上限 | 关键动作 |
|---|---|---|
| 主旨概括 | 55 秒 | 找主题词 + 找关联词 |
| 意图判断 | 60 秒 | 先找对策句 |
| 细节判断 | 70 秒 | 逐项回原文比对 |
| 标题填入 | 45 秒 | 先筛主题词 |
| 下文推断 | 45 秒 | 看尾句话题 |
| 语句排序 | 60 秒 | 首句 + 绑定两步 |
| 语句填空 | 45 秒 | 看空格位置 |

::: danger 一句话纪律
**片段阅读的答案永远在文段里，不在你的直觉里。**
一旦开始"我觉得应该是……"，就说明你在用语感替代方法，这时候正确率会立刻掉下来。
:::
