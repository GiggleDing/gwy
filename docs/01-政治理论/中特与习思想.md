# 中特与习思想

这一页只收录**必须能一字不差回忆出来的固定表述**。政治理论的选是/选非题，绝大多数在这里找答案。

## 一、习近平新时代中国特色社会主义思想

### 主体内容（三个层次）

| 表述 | 内容 |
|---|---|
| **十个明确** | 核心内容的集中概括（是什么） |
| **十四个坚持** | 基本方略（怎么做） |
| **十三个方面成就** | 实践成果（做成了什么） |

::: tip 记忆抓手
**明确 → 坚持 → 成就**，对应**是什么 → 怎么做 → 做成了什么**。这三个词序不要混。
:::

### 关键定位表述

| 表述 | 内容 |
|---|---|
| 中国共产党领导 | 中国特色社会主义**最本质的特征**，中国特色社会主义制度**最大优势** |
| 以人民为中心 | **根本立场**、**根本宗旨**的体现 |
| 两个结合 | 马克思主义基本原理同**中国具体实际**相结合、同**中华优秀传统文化**相结合 |
| 社会主要矛盾 | 人民日益增长的**美好生活需要**和不平衡不充分的发展之间的矛盾 |

::: danger 高频挖坑点
- "最本质的特征" 与 "最大优势" 都对，但**不能互换表述位置**
- "两个结合" 的第二条是**中华优秀传统文化**，不是"中华传统文化"（少了"优秀"）
- 社会主要矛盾表述里是"**美好生活需要**"，不是"物质文化需要"（那是旧表述）
:::

## 二、党的二十大

### 中心任务

> 团结带领全国各族人民全面建成社会主义现代化强国、实现第二个百年奋斗目标，**以中国式现代化全面推进中华民族伟大复兴**。

### 中国式现代化的五个特色

1. 人口规模巨大的现代化
2. 全体人民共同富裕的现代化
3. 物质文明和精神文明相协调的现代化
4. 人与自然和谐共生的现代化
5. 走和平发展道路的现代化

::: tip 串成一条线记
**人多 → 要共同富裕 → 物质精神都要 → 人与自然也要 → 对外走和平道路。**
顺着逻辑推，不容易漏项。
:::

### 本质要求（九个方面）

坚持中国共产党领导，坚持中国特色社会主义，实现高质量发展，发展全过程人民民主，丰富人民精神世界，实现全体人民共同富裕，促进人与自然和谐共生，推动构建人类命运共同体，创造人类文明新形态。

### 两步走战略安排

| 阶段 | 目标 |
|---|---|
| 到 2035 年 | 基本实现社会主义现代化 |
| 到本世纪中叶 | 建成社会主义现代化强国 |

::: warning 别记错年份
**2035 是"基本实现"，本世纪中叶是"建成"。** 两个动词不能互换。
:::

## 三、总体布局与战略布局

| 概念 | 内容 |
|---|---|
| 五位一体 | 经济、政治、文化、社会、生态文明建设 |
| 四个全面 | 全面建设社会主义现代化国家、全面深化改革、全面依法治国、全面从严治党 |
| 新发展理念 | 创新、协调、绿色、开放、共享 |
| 新发展格局 | 以国内大循环为主体、国内国际双循环相互促进 |

## 四、二十届三中全会

2024 年 7 月通过《中共中央关于进一步全面深化改革、推进中国式现代化的决定》。

| 项 | 内容 |
|---|---|
| 总目标 | 继续完善和发展中国特色社会主义制度，**推进国家治理体系和治理能力现代化** |
| 时间节点 | 到 **2035 年**，基本实现国家治理体系和治理能力现代化 |
| 阶段性节点 | 到 **2029 年**中华人民共和国成立八十周年时，完成本决定提出的改革任务 |

::: danger 最容易被偷换的一组
**"中国特色社会主义制度"** 与 **"国家治理体系和治理能力现代化"** —— 前者是"完善和发展"，后者是"推进"。
命题人常把两个宾语对调，或把"完善"换成"改革"。
:::

## 五、新质生产力

| 层 | 内容 |
|---|---|
| 是什么 | 由技术革命性突破、生产要素创新性配置、产业深度转型升级而催生 |
| 特点 | **创新** |
| 关键 | **质优** |
| 本质 | **先进生产力** |

::: tip 三个词各就各位
**特点是创新、关键在质优、本质是先进生产力。** 这三个词的位置是固定考法，会互相调换挖坑。
:::

## 六、其他高频固定表述

| 概念 | 核心表述 |
|---|---|
| 全过程人民民主 | 过程民主和成果民主、程序民主和实质民主、直接民主和间接民主、人民民主和国家意志相统一 |
| 人类命运共同体 | 建设持久和平、普遍安全、共同繁荣、开放包容、清洁美丽的世界 |
| 总体国家安全观 | 以人民安全为宗旨、以政治安全为根本、以经济安全为基础、以军事科技文化社会安全为保障、以促进国际安全为依托 |
| 乡村振兴总要求 | 产业兴旺、生态宜居、乡风文明、治理有效、生活富裕 |
| 共同富裕 | 是社会主义的本质要求，是中国式现代化的重要特征 |

::: danger 总体国家安全观的四组"以…为…"
**宗旨=人民安全；根本=政治安全；基础=经济安全；保障=军事科技文化社会安全；依托=促进国际安全。**
五组词极易错位，这是高频挖坑点，必须逐字记。
:::

## 七、党纪与党建

| 项 | 内容 |
|---|---|
| 党的自我革命 | 跳出治乱兴衰历史周期率的**第二个答案**（第一个答案是**人民监督**） |
| 纪律处分种类 | 警告、严重警告、撤销党内职务、留党察看、开除党籍 |
| 监督执纪"四种形态" | 批评教育、组织处理、纪律处分、立案审查 |

::: warning 两个答案不要混
**第一个答案：让人民来监督；第二个答案：自我革命。** 顺序和主体都不能错。
:::

## 八、考场动作

1. 选项里出现**数字**（2035、2029、本世纪中叶）→ 逐个核对，这是最常见的偷换位置
2. 选项里出现**动宾搭配**（完善 X、推进 Y）→ 核对宾语是否被对调
3. 选项里出现**"最""根本""唯一""完全"** → 先判断是否为固定表述，是则保留
