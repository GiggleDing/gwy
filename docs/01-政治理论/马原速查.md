# 马原速查

马原在政治理论里**几乎不考背诵，只考"用"**：给一句古诗、一个典故或一段讲话，让你判断体现哪条哲学原理。

> 所以这一页的重点不是背定义，而是**建立"现象 → 原理"的条件反射**。

## 一、辩证唯物论

| 原理 | 核心表述 | 识别信号 |
|---|---|---|
| 物质决定意识 | 物质第一性，意识是物质的反映 | "根据实际情况制定政策" |
| 意识的能动作用 | 意识能反作用于物质，具有目的性、计划性、创造性 | "xx 蓝图""规划""精神力量" |
| 物质与运动不可分 | 运动是物质的根本属性，静止是运动的特殊状态 | "刻舟求剑""变化发展" |
| 规律的客观性 | 规律不以人的意志为转移，但可以被认识和利用 | "违背规律受惩罚""因地制宜" |

::: tip 三条必定分清
- **物质决定意识** → 强调"从实际出发"
- **意识能动作用** → 强调"精神/规划的作用"
- **规律客观性** → 强调"不能违背，但可利用"
:::

## 二、唯物辩证法

### 两大特征

| 原理 | 要点 |
|---|---|
| 联系的普遍性、客观性、多样性 | 事物之间及内部诸要素相互影响、相互制约 |
| 发展的实质 | 新事物的产生和旧事物的灭亡；发展是前进性与曲折性的统一 |

### 三大规律

| 规律 | 内容 | 方法论 |
|---|---|---|
| **对立统一**（根本规律） | 矛盾双方既对立又统一，在一定条件下相互转化 | 一分为二、具体问题具体分析 |
| **质量互变** | 量变是质变的准备，质变是量变的必然结果 | 重视量的积累，又要抓住时机促成质变 |
| **否定之否定** | 事物发展是"肯定—否定—否定之否定"的前进上升过程 | 前途光明、道路曲折 |

### 五对范畴

| 范畴 | 关系 |
|---|---|
| 原因与结果 | 引起与被引起 |
| 必然与偶然 | 必然通过偶然开辟道路 |
| 可能与现实 | 可能在一定条件下转化为现实 |
| 现象与本质 | 现象是外部表现，本质是内在联系 |
| 形式与内容 | 内容决定形式，形式反作用于内容 |

## 三、认识论

| 原理 | 要点 |
|---|---|
| 实践是认识的基础 | 实践是认识的**来源、动力、目的、检验标准** |
| 认识的两次飞跃 | 感性认识 → 理性认识（第一次）；理性认识 → 实践（第二次） |
| 真理的客观性与条件性 | 真理是具体的、有条件的 |
| 真理的绝对性与相对性 | 绝对真理与相对真理的辩证统一 |

::: warning 最高频的判断
**"实践是检验真理的唯一标准"**——"唯一"是固定表述，不属于"过于绝对"的挖坑。
同理"人民群众是历史的创造者"里的"创造者"也是固定表述。**固定表述里的绝对词不要当成陷阱排除。**
:::

## 四、唯物史观

| 原理 | 要点 |
|---|---|
| 社会存在决定社会意识 | 社会意识具有相对独立性，可能超前或滞后 |
| 生产力与生产关系 | 生产力决定生产关系，生产关系反作用于生产力 |
| 经济基础与上层建筑 | 经济基础决定上层建筑，上层建筑反作用于经济基础 |
| 人民群众是历史的创造者 | 是历史的主体和创造者 |
| 社会基本矛盾 | 生产力与生产关系、经济基础与上层建筑的矛盾 |

## 五、古诗俗语 → 原理 映射表

**这是马原最高频的送分点，务必形成条件反射。**

| 古诗 / 俗语 | 对应原理 |
|---|---|
| 塞翁失马，焉知非福 | 矛盾双方在一定条件下相互转化 |
| 乐极生悲 / 否极泰来 | 矛盾双方相互转化 |
| 城门失火，殃及池鱼 | 事物是普遍联系的 |
| 唇亡齿寒 | 联系的普遍性 |
| 不积跬步，无以至千里 | 量变是质变的前提和必要准备 |
| 千里之堤，毁于蚁穴 | 量变引起质变 |
| 水滴石穿 | 量的积累达到一定程度引起质变 |
| 沉舟侧畔千帆过，病树前头万木春 | 新事物必然战胜旧事物 |
| 星星之火，可以燎原 | 新事物发展壮大 / 量变质变 |
| 青出于蓝而胜于蓝 | 发展的观点（运动、变化、发展） |
| 刻舟求剑 | 否认运动，形而上学的静止观 |
| 守株待兔 | 把偶然当必然，否认规律的客观性 |
| 揠苗助长 | 违背事物发展客观规律 |
| 因材施教 / 对症下药 | 具体问题具体分析（矛盾的特殊性） |
| 因地制宜 | 矛盾的特殊性，一切从实际出发 |
| 尺有所短，寸有所长 | 一分为二，矛盾特殊性 |
| 一叶障目，不见泰山 | 形而上学，孤立、片面地看问题 |
| 纸上得来终觉浅，绝知此事要躬行 | 实践是认识的来源 |
| 仁者见仁，智者见智 | 认识具有主体差异性（注意：不是"真理多元"） |
| 望梅止渴 | 意识的能动作用 |
| 邯郸学步 | 忽视矛盾的特殊性，生搬硬套 |
| 头痛医头，脚痛医脚 | 形而上学，割裂联系 |
| 千里之行，始于足下 | 量变质变 |

::: danger 最容易错的两个
1. **"仁者见仁，智者见智"** —— 体现的是**认识的主体差异性**，**不是**"真理多元"或"没有客观真理"。真理只有一个。
2. **"邯郸学步"** —— 体现的是**忽视矛盾特殊性**，**不是**"否定之否定"或"发展"。
:::

## 六、政治经济学核心结论

| 概念 | 要点 |
|---|---|
| 商品的二因素 | 使用价值 + 价值；价值是商品的社会属性，使用价值是自然属性 |
| 劳动的二重性 | 具体劳动创造使用价值，抽象劳动创造价值（**是理解政治经济学的枢纽**） |
| 价值量 | 由社会必要劳动时间决定，不由个别劳动时间决定 |
| 剩余价值 | 由雇佣工人在剩余劳动时间创造，被资本家无偿占有 |
| 资本的本质 | 不是物，而是以物为媒介的社会生产关系 |
| 资本主义基本矛盾 | 生产社会化与生产资料资本主义私人占有之间的矛盾 |

::: tip 一句话记牢
**具体劳动 ↔ 使用价值；抽象劳动 ↔ 价值。** 这一对映射是政治经济学部分的出题核心。
:::

## 七、科学社会主义

| 结论 | 要点 |
|---|---|
| 社会主义从空想变为科学 | 标志是《共产党宣言》发表（1848 年） |
| 两大理论基石 | 唯物史观 + 剩余价值学说 |
| 社会主义的本质 | 解放和发展生产力，消灭剥削、消除两极分化，最终达到共同富裕 |

## 八、考场动作

1. 看到**古诗/俗语/典故** → 先在脑内跑映射表，锁定原理，再看选项
2. 看到**领导人讲话引文** → 找"体现了什么哲学原理"，注意可能是多条原理并存
3. 遇到**绝对化表述** → 先判断是不是固定表述（是则保留，不是则优先排除）
