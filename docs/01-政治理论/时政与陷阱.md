# 时政与挖坑规律

时政内容每年变，但**考法和挖坑手法基本不变**。这一页给的是**框架 + 排坑清单**，具体条目需要你自己按最新文件补进去。

## 一、必考文件类型（每年固定出现）

| 类型 | 说明 | 重要度 |
|---|---|---|
| 党的全国代表大会报告 | 总纲性质，统领各方面 | 极高 |
| 中央全会决定 | 如二十届三中全会《决定》 | 极高 |
| 政府工作报告 | 每年两会通过 | 高 |
| 中央经济工作会议 | 总结当年、部署次年经济工作 | 高 |
| 中央一号文件 | 乡村振兴、"三农"工作 | 高 |
| 五年规划纲要 | 一个周期的命题总纲 | 极高 |
| 领导人重要讲话 | 各领域大会讲话 | 极高 |
| 新年贺词 | 年度热点集萃 | 中 |
| 《求是》重要文章 | 理论深化 | 中 |

::: warning 时效规律
**考前一年内的重大会议和文件是主战场，最近三个月的时政最密集。**
考前一个月不要再学新知识点，只做"唤醒"式回顾。
:::

## 二、时政从哪儿来（权威渠道）

| 渠道 | 用途 |
|---|---|
| **共产党员网**（12371.cn）→ "党的知识" | 党章、党内法规、党史、创新理论的官方出处 |
| **求是网**（qstheory.cn）→ "特别专题" | 领导人重要讲话与重要文章 |
| **人民网** → "习近平系列重要讲话数据库" | 按时间检索讲话，含"报道日历" |
| **学习强国 APP** | "要闻""综合""新思想"频道，可听可读 |
| 微信公众号"求是网""人民日报" | 每日时政高效获取 |

::: tip 碎片时段怎么用
把"学习强国"的要闻**当播报听**，不占用视觉注意力。通勤、排队时听一遍，能形成印象即可，不追求当时就记住。
:::

## 三、四类挖坑规律（本模块的核心）

政治理论题的干扰项，**几乎全落在下面四类里**。做题时逐项对照检查。

### 陷阱一：关键词替换

把政策原文里的修饰词、限定词换掉。

| 原文 | 被替换为 |
|---|---|
| 先进制造 | 传统制造 |
| 高质量发展 | 高速发展 |
| 中华优秀传统文化 | 中华传统文化 |
| 共同富裕 | 同步富裕 |

**应对**：对政策表述里的**形容词和限定词**保持高度敏感，读到就多看一眼。

### 陷阱二：顺序颠倒

把有固定逻辑顺序的概念对调。

| 正确顺序 | 被颠倒为 |
|---|---|
| 党的领导是根本保证，依法治国是基本方式 | 两者位置互换 |
| 第一个答案：人民监督；第二个答案：自我革命 | 序号对调 |
| 特点创新、关键质优、本质先进生产力 | 三个词错位 |

**应对**：凡是成组出现的概念，专门记**顺序**，不只记内容。

### 陷阱三：主次矛盾抓偏（张冠李戴）

把 A 领域的概念归到 B 领域。

| 概念 | 正确归属 | 被错归为 |
|---|---|---|
| 全过程人民民主 | 政治领域 | 经济领域 |
| 完善财政转移支付体系 | 深化财税体制改革 | 完善市场经济基础制度 |
| 完善产权制度 | 完善市场经济基础制度 | 要素市场化改革 |

**应对**：记概念时**连带记它属于哪个板块**，不要孤立地背名词。

### 陷阱四：表达过于绝对

| 类型 | 例子 |
|---|---|
| 程度夸大 | 把"重要支撑"说成"根本保证" |
| 范围扩大 | 把"部分地区"说成"全国" |
| 无中生有 | 编造一个原文没有的"首次""第一个" |

**应对**：看到"最""第一""根本""完全""唯一"先停一下，判断是否为固定表述。

::: danger 固定表述里的绝对词不要排除
这些是**正确的**固定表述，不是陷阱：
- 中国共产党领导是中国特色社会主义**最本质**的特征
- 实践是检验真理的**唯一**标准
- 人民群众是历史的**创造者**
- 共同富裕是社会主义的**本质要求**

**只有非固定表述里出现绝对词，才优先怀疑是陷阱。**
:::

## 四、排坑动作清单

做题时按这个顺序走，能挡掉大部分坑：

1. **先看问法** —— 选是还是选非？"正确的是"和"不正确的是"看错一次就是一题
2. **圈出时间词** —— "2035 年""本世纪中叶""2029 年"，年份最容易偷换
3. **圈出主体词** —— 谁做的、对谁做的
4. **逐项过四类陷阱** —— 关键词替换？顺序颠倒？张冠李戴？绝对化？
5. **两项犹豫时** —— 选与原文表述最接近的，不要选"听起来更漂亮"的

::: tip 一个反直觉的经验
政治理论题**不要靠"感觉哪个更像官方口吻"来选**。干扰项恰恰是被写得"很像官方"的那一个。
必须回到**具体的关键词、顺序、归属**上做判断。
:::

## 五、每日积累的最小动作（10–20 分钟）

| 时段 | 动作 |
|---|---|
| 早上 | 读学习强国"要闻"前 5 条，重点看领导人活动和重要会议 |
| 晚上 | 学固定模块（马原、习思想），一周两篇《求是》文章划核心表述 |
| 每周 | 把本周时政按"国家政策—地方实践"两条线归位，用一张纸画逻辑树 |
| 每月 | 整理当月新提法、新文件题，写进笔记 |

::: warning 三字诀
**先理解再记忆、先主干后细节、先框架后填充。**
政治理论是"逻辑题"不是"默写题"，顺藤摸瓜远比大海捞针高效。
:::

## 六、考前冲刺动作

考前两周，时政部分只做三件事：

1. 过一遍自己的**陷阱清单**（不是过知识点）
2. 过一遍**关键数字**（年份、条数、次序）
3. 做近三年真题的政治理论部分，**只看错项错在哪一类**

::: danger 不要在考前去翻新文件
考前翻没学过的新文件，只会产生焦虑，不会转化为分数。**这个阶段是"唤醒"不是"重建"。**
:::
