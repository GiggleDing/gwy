# 套卷记录

**这一页只干一件事：把每次套卷的成绩挂上去，看曲线怎么长。**

模块内正确率是「零件质量」，套卷折合分是「整车性能」——中间隔着**用时分配、心态波动、涂卡节奏**三个变量。这一页记录的是整车。

::: tip 看这页的心态
**曲线是给自己做标定用的，不是给自己打分的。** 一套卷只是一个数据点，它说「你现在在这」，不说「你行不行」。
:::

:::

绝对正确率会被「这套卷难不难」污染。**差值 = 我的正确率 − 题库同题平均正确率**，把卷子难度扣掉，剩下的才是真本事。

- **政治理论 +5.8、常识判断 +4.5**：略高于大盘，说明零散积累有效，继续走碎片路线

- **数量关系不参与统计**：全蒙的差值没有意义

<GkChart name="paper-time-account" />

首考严格限时 120 分钟，全卷实际用时 119.9 分钟——**刚好压线**。所以问题不是「做不完」，而是**内部配速**：

- **资料分析 +5.8′**（预算 25′ → 实际 30.8′）：20 题全对，但均时 **92 秒/题**，踩在 90 秒止损线上
- **判断推理 +3.0′**（35′ → 38′）：被图形推理 4 道超时题吃掉的
- **数量关系 −8.9′**（10′ → 1.1′）：不是主动放弃，是**被前两块挤空**的

> **数量关系是症状，不是病。** 真正的病灶是资料和判断的超支。先修配速，数量才轮得到时间。

## 五、每套必须回填的四个数

套卷结束**当场记，别过夜**（复盘方法见[模考复盘法](/00-总览/模考复盘法)）：

1. **各模块对题数** → 挂进「分数走势」
2. **各模块用时** → 挂进「时间账」
3. **蒙对题数** → 算「校正后分数」，防止虚高
4. **本次唯一改进项** → 一句话，写不出来＝这次没复盘

::: danger 一次只改一个变量
一次套卷能改进的只有一件事。四个数都记，但**改进动作只写一条**。同时改三条，下周连哪条生效了都不知道。
:::
