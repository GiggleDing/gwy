# 模考复盘法

**不复盘的模考，等于花两小时生成了一组随机数。**

复盘的目的不是"知道错了几道"，而是**定位到可改进的具体动作**。

## 一、先记三组数

每次模考后，先算这三组数，再谈别的：

| 指标 | 怎么算 | 看什么 |
|---|---|---|
| 模块正确率 | 该模块做对数 ÷ 题量 | 与目标正确率的差值 |
| 模块用时 | 该模块起止时间相减 | 与计划用时的差值 |
| 超时题数 | 单题超过止损线的题数 | 超时题里做对了几道 |

::: tip 关键判断：超时的题做对了吗
**超时做对 = 隐性亏损**（吃掉后面简单题的时间）；**超时做错 = 双重亏损**。如果某模块超时题大量存在，先解决用时，不要先解决正确率。
:::

## 二、错题四类归因

每道错题必须归到**唯一一类**。归不进去，说明还没想清楚为什么错。

| 类型 | 特征 | 对应动作 |
|---|---|---|
| **知识盲区** | 考点完全没见过，或见过但忘了 | 回对应模块页补，进遗忘曲线排期 |
| **审题偏差** | 考点会，但看错了问法（选是/选非、同比/环比、主体范围） | 提炼成"陷阱条目"记入错题归因表 |
| **计算失误** | 方法对、式列对，算错 | 检查速算法使用是否规范（截位位数、量级） |
| **时间不够** | 根本没做或仓促蒙 | 回到战略地图调时间分配，不是补知识 |

::: warning 最常见的误判
把「审题偏差」当成「知识盲区」，然后回去重学一遍已经会的知识点。**这是最浪费时间的错误。**
判断方法：如果看完解析的第一反应是"哦原来问的是这个"，那就是审题问题，不是知识问题。
:::

## 三、复盘流程（40 分钟）

1. **10 分钟**：录入数据，填模块正确率 / 用时 / 超时题数三张表
2. **15 分钟**：逐题归因，四类各归各位，把「审题偏差」和「计算失误」单独列出来
3. **10 分钟**：只挑**一个**最严重的问题，写出具体的改进动作
4. **5 分钟**：把需要记的知识点写进遗忘曲线排期

::: danger 一次只改一个变量
模块内 80% 正确率的人，一次能改进的只有一件事。同时改三件事，下周连哪件事生效了都不知道。
:::

## 四、单次模考只看四个数

| 数 | 含义 | 健康区间 |
|---|---|---|
| 各模块正确率 | 能力现状 | 资料 ≥ 85%、判断/言语 ≥ 75% |
| 计划用时 vs 实际用时 | 时间控制力 | 偏差在 ±2 分钟内 |
| 蒙对率 | 运气成分 | 明显高于 25% 说明这次虚高 |
| 重复错误类型 | 真正的短板 | 同一类型连错 3 次以上＝必须专项 |

::: tip 蒙对率怎么估
统计"完全没思路、纯蒙"的题里对了多少。如果 10 道蒙对 5 道，这次的分数比真实水平高约 2–3 分。**不要用虚高的分数安慰自己。**
:::

## 五、模考记录建议

每次模考固定记这些字段，便于横向比较：

| 字段 | 示例 |
|---|---|
| 日期 / 卷别 | 2026 副省级 |
| 各模块正确率 | 资料 17/20、判断 25/35…… |
| 各模块用时 | 资料 31 min、判断 35 min…… |
| 超时题数 | 资料 3、逻辑 2 |
| 归因分布 | 知识 4、审题 3、计算 2、时间 6 |
| 本次唯一改进项 | 资料分析先看问题再看材料 |

## 六、复盘之后做什么

| 归因结果 | 下一步动作 |
|---|---|
| 知识盲区为主 | 回模块页补速查卡，进遗忘曲线排期 |
| 审题偏差为主 | 整理陷阱清单，考前集中过一遍 |
| 计算失误为主 | 专项练速算，检查截位规则 |
| 时间不够为主 | 调整作答顺序和止损线，不补知识 |

::: tip 复盘的最高标准
复盘完能说出一句具体的话，比如"下次做资料分析，我先花 20 秒看 5 道题的题干，再读材料"。
如果只能说"我下次要更认真"，那这次复盘白做了。
:::
