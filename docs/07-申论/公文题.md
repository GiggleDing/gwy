# 公文题

**分值 20–25 分，是"格式分 + 内容分"的组合题。** 格式错一项就白白丢分，所以这一页的格式部分必须记准。

## 一、格式五要素

| 要素 | 说明 | 位置 |
|---|---|---|
| **标题** | 发文机关 + 事由 + 文种，或只写"关于……的……" | 第一行居中 |
| **主送机关（称谓）** | 收文对象 | 标题下、顶格 |
| **正文** | 开头 + 主体 + 结语 | |
| **发文机关** | 落款单位 | 正文右下 |
| **日期** | 成文日期 | 发文机关下方 |

::: danger 格式最容易丢分的三处
1. **标题漏写文种** —— 要有"倡议书""建议书""讲话稿"这类文种词
2. **忘记落款和日期** —— 只要题目没说"不必写落款"，就要写
3. **主送机关位置错** —— 要顶格写，不是居中
:::

::: tip 但也要看题
如果题目明确说"不必考虑格式"或"只写正文"，就**不要**写标题、称谓、落款——多写也会扣分。
**题干里关于格式的每一句话都要读到。**
:::

## 二、正文的三段结构

```
① 开头（发文缘由）  →  为什么写这份文件
② 主体（核心内容）  →  具体要说什么（这是主要得分区）
③ 结语（呼吁/要求）  →  希望怎么做 / 请予支持 / 特此说明
```

::: tip 篇幅比例
- 开头：约 15%
- **主体：约 70%**
- 结语：约 15%

**主体部分同样要分条**，不要写成一大段。
:::

## 三、常见文种速查

### 倡议书

| 项 | 内容 |
|---|---|
| 标题 | 关于……的倡议书 |
| 称谓 | 广大市民朋友们 / 全体同学 |
| 开头 | 说明背景与目的 |
| 主体 | 倡议的具体内容（分条） |
| 结语 | 发出号召 |
| 落款 | 单位 + 日期 |

### 公开信

结构同倡议书，但语气更正式，通常针对具体问题作出回应或说明。

### 讲话稿 / 发言稿

| 项 | 内容 |
|---|---|
| 标题 | 在……上的讲话 |
| 称谓 | 各位领导、同志们 |
| 开头 | 问好 + 说明来意 |
| 主体 | 分点阐述（通常 3 点） |
| 结语 | 表示感谢 / 表达期望 |
| 落款 | **通常不写落款和日期**（口语化场景） |

### 工作建议 / 建议书

| 项 | 内容 |
|---|---|
| 标题 | 关于……的建议 |
| 称谓 | 有关单位 / 领导 |
| 主体 | 建议的具体内容（分条，可加理由） |
| 结语 | 供参考 / 请审阅 |

### 汇报材料 / 工作总结

| 项 | 内容 |
|---|---|
| 标题 | 关于……工作的汇报 |
| 主体 | 基本情况 + 主要做法 + 存在问题 + 下一步打算 |

### 短评 / 编者按 / 宣传稿

| 文种 | 特点 |
|---|---|
| 短评 | 观点鲜明，篇幅短，**不需要落款** |
| 编者按 | 篇幅极短，起引导阅读的作用，**不需要落款** |
| 宣传稿 | 面向公众，语言生动，要有号召力 |

::: warning 哪些文种不写落款
**讲话稿、发言稿、短评、编者按、新闻报道、讲解稿** —— 这些通常不写落款和日期。
判断依据：如果是"当面说的"或"刊发的"，一般不需要落款。
:::

## 四、内容从哪儿来

::: danger 公文题的正文内容，和单一题一样来自材料
**不要自己发挥。**
"倡议内容""建议内容""做法"这些，全都在材料里——你要做的是**找出来 + 组织成公文的形式**。

很多人栽在"觉得公文要写得像样"，于是自己编内容，结果要点全漏。
:::

## 五、语言风格

| 文种 | 语言 |
|---|---|
| 倡议书、宣传稿 | 有感召力，可用排比 |
| 建议书、汇报材料 | 平实、客观 |
| 讲话稿 | 口语化，有互动感 |
| 短评 | 观点鲜明，有态度 |

::: tip 无论哪种文种，都要做到
1. **分条** —— 主体内容一定分点
2. **动宾结构** —— 每条以动词开头
3. **不用修辞堆砌** —— 有信息量比漂亮重要
:::

## 六、作答时间与检查

| 阶段 | 用时 |
|---|---|
| 读题、确定文种和格式 | 3 分钟 |
| 回材料找要点 | 10 分钟 |
| 组织成文 | 15–20 分钟 |
| 检查 | 2 分钟 |

### 最后 2 分钟检查什么

- [ ] 标题有没有写、有没有文种词
- [ ] 称谓有没有写、位置对不对
- [ ] 落款和日期要不要写（看文种和题干）
- [ ] 主体有没有分条
- [ ] 字数够不够
- [ ] 有没有漏掉的要点

::: danger 公文题是"格式分"最容易被白送的地方
**格式占分不少，但只是几个固定动作。** 因为忘了写落款丢 2 分，比因为少写一个要点丢 2 分更冤枉。
每次做公文题，都按上面的清单过一遍。
:::
