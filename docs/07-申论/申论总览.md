# 申论 · 模块总览

**副省级卷：5 道大题，考试时长 180 分钟，满分 100 分。**

> 申论的核心认知只有一句：**答案都在材料里。**
> 你不是在"写文章"，你是在**"从材料里找答案并规范表达"**。

## 一、题型构成

分值是这样分布的：

<GkChart name="sl-score-share" />

四类题型各自的题量与性质：

- **单一题（归纳概括）** 1–2 题 —— 送分题
- **综合题（词句理解 / 观点分析）** 1 题 —— 分析题
- **公文题（应用文写作）** 1 题 —— 格式 + 内容
- **文章写作（大作文）** 1 题 —— 分值最高

## 二、时间分配（180 分钟）

<GkChart name="sl-time-plan" />

三个要点：

- **通读材料 30–40 分钟**：边读边标记，为后面定位做准备
- **文章写作 55–60 分钟**：列提纲 10 分钟 + 写作 45 分钟
- **检查 5 分钟**：主要看有没有漏答题、字数是否达标

::: warning 大作文不要留到最后 25 分钟
**大作文占 35–40 分，是最大的一块。**
如果前面小题拖太久，大作文只能草草写 600 字——这是申论低分最常见的原因。
**建议倒排时间：先确保大作文有 55 分钟。**
:::

## 三、四个必守原则

### 原则一：材料为王

::: danger 最常见的错误
**凭自己的知识和经验作答。**
申论的得分点是材料里的**关键词**，阅卷按点给分。
你自己想出来的漂亮句子，阅卷人找不到对应点，就是 0 分。
:::

### 原则二：分条作答

**所有小题都要分条。** 阅卷是按点给分的，混在一段里会让阅卷人找不到点。

### 原则三：用规范词，但不生造

| 材料原文 | 规范表达 |
|---|---|
| 村里修了水泥路、装了路灯、建了文化广场 | **完善基础设施** |
| 没人管、没人问 | **管理缺位 / 责任落实不到位** |
| 大家都不知道、不清楚 | **宣传不到位** |

::: tip 规范词从哪来
从**做题积累**中来，不是从背手册中来。
每做完一道题，把参考答案里的规范表述抄进 [错题归因表](/08-工具/错题归因表)，考前集中过一遍。
:::

### 原则四：字数是硬指标

**字数不够直接扣分，字数超标也会扣分。** 每道题的作答区域要写满 90% 以上。

## 四、各题型的答题框架（预告）

| 题型 | 核心框架 |
|---|---|
| 单一题 | 概括对象 + 分条罗列（动宾结构） |
| 综合题 | 观点 + 分析 + 结论 |
| 公文题 | 标题 + 称谓 + 正文 + 落款 |
| 文章写作 | 总论点 + 3 个分论点 + 论据 |

## 五、与行测的联动

::: tip 政治理论的权威表述直接可用
你在政治理论模块背的那些标准表述（中国式现代化、新发展理念、高质量发展、新质生产力等），
**可以直接写进大作文的论证里，显著提升文章的政治高度。**

**这是"一鱼两吃"——政治理论的投入同时提升两个模块。**
:::

## 六、每日最小动作

| 动作 | 量 | 说明 |
|---|---|---|
| 每周 | 实写 1 道小题 | **必须动手写**，不能只看不写 |
| 每周 | 精读 1 篇范文 | 拆解它的分论点和论据组织 |
| 每天 | 抄 5 个规范词 | 从做题和范文中提取 |

::: danger 一条硬纪律
**申论绝不能只看不写。**
看答案时觉得"我也能想到"，动手时写不出来——这是申论最典型的自我欺骗。
**每周至少动手实写 1 道，写完后对比参考答案找差距。**
:::
