# 文章写作

**35–40 分，申论分值最高的一题。** 也是唯一"结构决定下限、素材决定上限"的题型。

## 一、时间预算

| 阶段 | 用时 |
|---|---|
| 审题 + 定总论点 | 8 分钟 |
| 找分论点 + 列提纲 | 7 分钟 |
| 写作 | 40–45 分钟 |
| **合计** | **55–60 分钟** |

::: danger 必须先给大作文留够时间
**大作文占 35–40 分。** 前面小题拖到只剩 25 分钟写作文，是申论低分的第一原因。
**倒排时间**：从 180 分钟里先划出 55 分钟给大作文，剩下的再分配给小题。
:::

## 二、结构：总—分—总

```
标题
├─ 开头段：引出话题 + 亮明总论点
├─ 分论点一：段首句 + 论证
├─ 分论点二：段首句 + 论证
├─ 分论点三：段首句 + 论证
└─ 结尾段：总结 + 升华
```

::: tip 为什么要"分论点放段首"
阅卷时间极短，**段首句是阅卷人唯一会认真看的句子**。
把分论点写清楚放在段首，是这篇作文能不能被看见的关键。
:::

## 三、标题怎么写

**公式**：主题词 + 观点

| 类型 | 例 |
|---|---|
| 对仗式 | 以创新驱动发展，用实干成就未来 |
| 动宾式 | 让创新成为高质量发展的第一动力 |
| 判断式 | 高质量发展是实现现代化的必由之路 |

::: warning 三种失败的标题
1. **没有主题词** —— "论发展"（太宽泛）
2. **只有主题词没有观点** —— "谈谈创新"（没有态度）
3. **太文艺、看不懂** —— 阅卷人看不懂就是失败
:::

## 四、开头段怎么写

**三步**：

```
① 引题   →  用背景、政策、现象引出话题
② 过渡   →  一两句话点明问题或意义
③ 亮观点 →  明确写出总论点
```

::: tip 开头段控制在 150 字左右
不要长篇铺陈。**阅卷人只关心你的总论点是什么。**
:::

## 五、分论点怎么找

### 三个来源

| 来源 | 说明 |
|---|---|
| **题干** | 题干里的关键词往往直接给出分论点方向 |
| **材料** | 材料里的对策、意义、经验可以提炼成分论点 |
| **政治理论素材** | 新发展理念、五位一体等框架可以直接用 |

### 常用的三种逻辑

| 逻辑 | 例 |
|---|---|
| **并列式** | 从"制度、技术、人才"三个方面展开 |
| **递进式** | 从"是什么、为什么、怎么办"展开 |
| **主体式** | 从"政府、企业、个人"三个层面展开 |

::: danger 分论点必须互斥
**三个分论点不能互相包含或重复。**
"加强制度建设"和"完善制度体系"是同一个点，不能算两个分论点。
:::

## 六、论证怎么写

### 一段分论点的标准结构

```
① 段首句（分论点）        →  1 句
② 理论阐述               →  2–3 句，解释为什么
③ 事实论据（例证）        →  2–3 句，具体例子
④ 小结回扣               →  1 句，回到分论点
```

### 两种论据

| 类型 | 说明 |
|---|---|
| **例证** | 具体事例（政策、案例、数据） |
| **理证** | 道理分析、逻辑推导 |

::: tip 优先用"理证 + 例证"组合
只有例证显得单薄，只有理证显得空。**一段里两者都有，才立得住。**
:::

## 七、可直接调用的政治理论素材

**这是"一鱼两吃"的地方**——你在政治理论模块背的内容，直接搬到这里。

| 素材 | 可论证的主题 |
|---|---|
| 中国式现代化（五个特色） | 发展道路、共同富裕 |
| 新发展理念（创新协调绿色开放共享） | 高质量发展 |
| 新质生产力 | 科技创新、产业升级 |
| 全过程人民民主 | 基层治理、群众参与 |
| 总体国家安全观 | 安全与发展 |
| 人与自然和谐共生 | 生态文明 |
| 人类命运共同体 | 对外开放、国际合作 |

::: tip 具体怎么用
不要整段引用，**把关键词嵌进句子里**：
> 坚持**创新发展**，把科技自立自强作为战略支撑，加快形成**新质生产力**。

这样显得有政治高度，又不是硬搬。
:::

## 八、结尾怎么写

**两步**：

```
① 总结分论点     →  一句话收束
② 升华/展望      →  联系更大的意义
```

::: warning 不要写空话
"让我们携手共进、共创美好未来"这类句子**没有信息量**，阅卷人不会加分。
结尾最好回应总论点，并落到"具体怎么干"上。
:::

## 九、卷面与字数

| 项 | 要求 |
|---|---|
| 字数 | 题目要求 800–1000 字，写到 **950 字左右** |
| 段落 | 5–6 段，每段 150–200 字 |
| 卷面 | 不涂改，字体清晰 |
| 分论点位置 | **段首**，且三个分论点句式尽量一致 |

::: danger 三条硬纪律
1. **必须写够字数** —— 字数不够直接扣分，且扣得不轻
2. **分论点必须段首** —— 不要藏在段中间
3. **不要出现明显的政治性错误** —— 涉及政治表述时，只写你有把握的
:::

## 十、备考动作

| 动作 | 频率 | 说明 |
|---|---|---|
| 每周精读 1 篇范文 | 每周 | 拆解它的分论点怎么立、论据怎么配 |
| 每周列 1 个提纲 | 每周 | **只列提纲不写全文**，练"8 分钟定论点" |
| 每两周实写 1 篇 | 每两周 | 必须动手写完整篇 |
| 积累素材 | 每天 | 从政治理论学习中顺手摘 |

::: tip 提纲要练到什么程度
**8 分钟内能定出：总论点 + 3 个分论点 + 每段的论据方向。**
练到这个程度，考场上写 900 字就是机械执行，不会卡壳。
:::
