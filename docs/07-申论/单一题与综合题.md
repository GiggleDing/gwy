# 单一题与综合题

## 第一部分：单一题（归纳概括）

**申论里最简单的送分题。** 只要会"找 + 抄 + 提炼"，分就到手了。

### 一、概括对象有哪几类

| 问法 | 找什么 |
|---|---|
| 概括问题 / 困境 / 不足 | 材料中的**负面表述** |
| 概括原因 | "因为""由于""源于"后面的内容 |
| 概括对策 / 做法 / 措施 | "应该""必须""需要"及具体做法 |
| 概括影响 / 意义 / 作用 | 结果性、评价性表述 |
| 概括特点 / 特征 | 描述性、区别性表述 |
| 概括变化 | 前后对比（过去 vs 现在） |

### 二、四步操作

```
第 1 步  看题干，明确概括对象和范围（哪几则材料）
第 2 步  回材料找答案句（划出关键词）
第 3 步  提炼：去掉例子、去掉修饰词、去掉数据
第 4 步  分条罗列，每条用动宾结构开头
```

### 三、提炼示例

::: tip 从材料到答案
**材料原文**：
> 村里修了水泥路，安装了路灯，还建了一个文化广场，村民晚上终于有地方活动了。

**提炼后**：
> 完善基础设施。硬化道路、安装路灯、建设文化广场，丰富村民文化生活。
:::

**提炼动作分解**：
| 原文 | 处理 |
|---|---|
| 水泥路、路灯、文化广场 | 归纳为"基础设施" |
| 修、安装、建 | 归纳为"完善" |
| "村民晚上终于有地方活动了" | 提炼为"丰富村民文化生活" |

### 四、分条的三个要求

| 要求 | 说明 |
|---|---|
| **分条** | 用"1. 2. 3."或"一是、二是"标号 |
| **动宾结构** | 如"完善基础设施""加强监管力度" |
| **前置小标题（可选）** | 如果题目分值高，可以加简短小标题 |

::: danger 三个最常见的失分点
1. **把例子写进答案** —— 例子是材料的论据，不是答案。**答案要的是概括，不是复述**
2. **不分条** —— 阅卷按点给分，混在一段里找不到点就丢分
3. **用自己的话重新表述** —— 申论按**关键词**给分，你换一个说法，阅卷人可能找不到对应点
:::

### 五、字数控制

| 题量 | 建议条数 |
|---|---|
| 150 字 | 4–5 条 |
| 200 字 | 5–6 条 |
| 300 字 | 6–8 条 |

**宁多勿少**，把字数写满 90% 以上。

## 第二部分：综合题

### 一、词句理解题

**问法**："谈谈你对'XX'的理解""解释'XX'的含义"

**答题框架（三段式）**：

```
① 解释含义    →  这句话说的是什么（表层 + 深层）
② 展开分析    →  为什么这么说 / 表现在哪里 / 有什么影响
③ 得出结论    →  因此应该怎么做
```

::: tip 结构比例
- 解释含义：约 20% 篇幅
- 展开分析：约 **60%** 篇幅（这是主要得分区）
- 得出结论：约 20% 篇幅

**很多人把解释含义写太多，分析写太少，直接丢了主要得分点。**
:::

### 二、观点分析题

**问法**："谈谈你对 XX 观点的看法""XX 的说法是否正确"

**答题框架**：

```
① 表态      →  正确 / 错误 / 片面（必须明确表态）
② 理由      →  从材料找依据支撑你的表态
③ 结论      →  正确的怎么落实；错误的怎么纠正
```

::: warning 观点必须明确
**不能"既对又不对"地模糊表述。**
如果材料确实支持"片面"的判断，就直接写"该观点有一定道理，但过于绝对/片面"——**表态要清晰，不要回避。**
:::

### 三、分析题的共同纪律

| 纪律 | 说明 |
|---|---|
| **观点从材料来** | 不能自己编观点，要从材料中推导 |
| **分析要分点** | 理由部分也要分条，不要写成一大段 |
| **要点齐全优先** | 宁可要点多、表述糙，不要要点少、表述美 |
| **不写空话** | "具有重要意义"这类没有信息量的句子不要占字数 |

### 四、综合题的时间控制

| 题型 | 用时 | 说明 |
|---|---|---|
| 词句理解 | 20–25 分钟 | |
| 观点分析 | 20–25 分钟 | |

::: danger 综合题最容易超时
因为"要分析"这个动作很容易让人想太多。
**记住：分析的内容也必须来自材料**，不是让你展开自由论述。想清楚了就不慢。
:::
