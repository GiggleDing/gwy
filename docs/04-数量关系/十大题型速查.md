# 十大题型速查

按"该学的顺序"排列：前面的必须掌握，后面的可以放弃。

---

## 一、工程问题（必学，方法固定）

### 核心公式

$$\text{工作量} = \text{效率} \times \text{时间}$$

### 两种赋值法

| 场景 | 赋值方式 |
|---|---|
| 已知各主体**单独完工时间** | 赋值总量为这些时间的**最小公倍数** |
| 已知各主体的**效率比** | 直接赋值效率为比例值 |

### 例题

甲单独做 10 天完成，乙单独做 15 天完成，两人合作几天完成？

$$
\begin{aligned}
\text{赋值总量} &= 30 \qquad (10 \text{ 和 } 15 \text{ 的最小公倍数}) \\[6pt]
\text{甲效率} &= 30 \div 10 = 3 \\[6pt]
\text{乙效率} &= 30 \div 15 = 2 \\[6pt]
\text{合作效率} &= 3 + 2 = 5 \\[6pt]
\text{时间} &= 30 \div 5 = 6 \ \text{(天)}
\end{aligned}
$$

::: tip 识别信号
题干出现"甲单独…天完成""效率提高 20%""完成一半后增派人员" → 工程问题，先想赋值。
:::

## 二、经济利润问题（必学）

### 核心公式

$$
\begin{aligned}
\text{利润} &= \text{售价} - \text{进价} \\[6pt]
\text{利润率} &= \frac{\text{利润}}{\text{进价}} \\[6pt]
\text{售价} &= \text{进价} \times (1 + \text{利润率}) \\[6pt]
\text{打 } n \text{ 折} &= \text{原价} \times \frac{n}{10}
\end{aligned}
$$

### 常用技巧

| 技巧 | 说明 |
|---|---|
| 赋值成本 | 题干含比例关系时，赋成本为 100 或整十数 |
| 列表法 | 分段计费、多次调价时，列表梳理变量 |

::: warning 打折不是"减去"
**打 8 折 $=$ 原价 $\times 0.8$**，不是"减 8 折"。
"满 200 减 50" 和 "打 8 折" 是完全不同的事，审题时看清楚。
:::

## 三、容斥问题（必学，背公式即可）

### 两集合

$$A + B - A \cap B = \text{总数} - \text{都不}$$

### 三集合（标准型）

$$A + B + C - A \cap B - A \cap C - B \cap C + A \cap B \cap C = \text{总数} - \text{都不}$$

### 三集合（非标准型）

$$A + B + C - \text{只满足两个的} - 2 \times \text{三者都满足} = \text{总数} - \text{都不}$$

::: tip 识别信号
出现"既…又…""三者交集""不少于两项" → 容斥问题，画文氏图标已知数。
:::

## 四、基础应用题（必学，最常见）

### 方程法三步

1. **设未知数**（尽量设题目问的量，或设关系最核心的量）
2. **找等量关系**（题干里"相等""一样多""比…多"的地方）
3. **解方程**

### 设未知数的技巧

| 场景 | 设法 |
|---|---|
| 出现"甲是乙的 3 倍" | 设乙为 $x$，甲为 $3x$ |
| 出现连续量 | 设中间的为 $x$ |
| 出现比例 | 设比例系数为 $x$ |

::: tip 别急着列方程
先扫一眼选项——**如果选项是具体数值，优先代入验证**，往往比列方程快。
:::

## 五、年龄问题（必学，成本极低）

### 两条规律

1. 年龄差永远不变
2. 年龄倍数随时间推移越来越小

::: tip 识别信号
题干出现"今年""$n$ 年后""年龄是…倍" → 年龄问题，抓年龄差。
:::

## 六、星期日期问题（必学，成本极低）

### 核心数据

| 项 | 天数 |
|---|---|
| 平年 | $365 = 52 \times 7 + 1$ 天 |
| 闰年 | $366 = 52 \times 7 + 2$ 天 |

### 闰年判断

$$
\begin{aligned}
&\text{能被 } 4 \text{ 整除，且不能被 } 100 \text{ 整除} \;\Rightarrow\; \text{闰年} \\[6pt]
&\text{能被 } 400 \text{ 整除} \;\Rightarrow\; \text{闰年}
\end{aligned}
$$

::: warning 例外记牢
**1900 年不是闰年**（能被 100 整除但不能被 400 整除）。
**2000 年是闰年**（能被 400 整除）。
:::

### 周期问题

找周期 → 算余数 → 余数为 0 就是周期末尾。

## 七、行程问题（学基础，放弃难题）

### 核心公式

$$
\begin{aligned}
\text{路程} &= \text{速度} \times \text{时间} \\[6pt]
\text{相遇：路程和} &= \text{速度和} \times \text{时间} \\[6pt]
\text{追及：路程差} &= \text{速度差} \times \text{时间}
\end{aligned}
$$

### 流水行船

$$
\begin{aligned}
\text{顺水速度} &= \text{船速} + \text{水速} \\[6pt]
\text{逆水速度} &= \text{船速} - \text{水速}
\end{aligned}
$$

::: danger 平均速度最常见的错误
**$\text{平均速度} = \dfrac{\text{总路程}}{\text{总时间}}$**，**不是**两段速度的算术平均。

例：去时 60 km/h，回时 40 km/h，$\text{平均速度} = \dfrac{2 \times 60 \times 40}{60 + 40} = 48$ km/h，不是 50。
:::

::: warning 什么时候放弃
出现"第 3 次相遇""多次往返""分段变速"这类 → 直接跳过。
:::

## 八、概率问题（学古典概型）

### 核心公式

$$
\begin{aligned}
\text{古典概型：}\quad P &= \frac{\text{满足条件的情况数}}{\text{总情况数}} \\[6pt]
\text{逆向公式：}\quad P(A) &= 1 - P(\overline{A})
\end{aligned}
$$

### 独立重复试验

$$P = \mathrm{C}_n^k \, p^k (1 - p)^{\,n - k}$$

::: tip 逆向思维优先
题目出现"至少有一个""至少一次" → 先算它的反面，用 1 减。
这比正面分类讨论快得多。
:::

## 九、几何问题（学基础）

### 常用公式

| 图形 | 公式 |
|---|---|
| 三角形面积 | $\frac{1}{2} \times \text{底} \times \text{高}$ |
| 圆面积 / 周长 | $\pi r^2$ / $2 \pi r$ |
| 梯形面积 | $\frac{1}{2}(\text{上底} + \text{下底}) \times \text{高}$ |
| 圆柱体积 | $\pi r^2 h$ |
| 圆锥体积 | $\frac{1}{3} \pi r^2 h$ |
| 球体积 | $\frac{4}{3} \pi r^3$ |
| 勾股定理 | $a^2 + b^2 = c^2$ |

### 相似比关系

$$\text{边长比} = k \;\Rightarrow\; \text{面积比} = k^2 \;\Rightarrow\; \text{体积比} = k^3$$

::: tip 最高频的技巧
**遇到不规则图形，先想"割补法"和"等面积法"**，比硬算快得多。
:::

## 十、最值问题（选学）

### 两种类型

| 类型 | 问法 | 方法 |
|---|---|---|
| 和定最值 | "总和一定，求某量最大/最小" | 让其他量尽可能小/大 |
| 最不利原则 | "至少…才能保证" | **最不利情况 $+ 1$** |

::: tip 最不利原则的关键
题目问"至少摸几个球才能保证有 2 个同色"，答案是"**每种颜色都先摸 1 个，再摸 1 个**"。
关键在于构造**最坏的情况**，再加 1。
:::

## 附：秒杀工具包

### 数字特性（不用算出答案）

| 特性 | 用法 |
|---|---|
| **整除** | 若答案必须能被 3 整除，直接筛选项 |
| **奇偶** | 两个数之和为奇数 → 一奇一偶 |
| **倍数** | "甲是乙的 3 倍" → 甲必能被 3 整除 |

### 代入排除法

::: tip 使用时机
**选项是具体数值，且题目问的是"是多少"** → 优先代入，从最好算的选项开始。
:::

### 三个整除判断法

| 数 | 判断方法 |
|---|---|
| 3 | 各位数字之和能被 3 整除 |
| 9 | 各位数字之和能被 9 整除 |
| 4 | 末两位能被 4 整除 |
