# 数量关系 · 模块总览

**15 题，全卷最难、最耗时的模块。** 副省级比市地级多 5 题，这是副省级卷唯一的"额外负担"。

> 这个模块的备考目标不是"做完 15 题"，而是 **"稳定做对 5 题、其余果断蒙"**。
> **先学会哪些题不做，比学会做题更重要。**

## 一、定位

- **题量**：15 题（副省级）／10 题（市地级、行政执法类）——副省级多出的那 5 题，全在这里
- **建议用时**：**6 分钟**，只做 3–5 题，其余统一蒙
- **单题上限**：**90 秒，到线立即放弃，不回头**

::: danger 这个模块唯一的铁律
**数量关系超时是永久放弃，不是"先跳过回头再看"。**
其他模块跳过还能回来，数量关系回头的时间成本比它本身的分值更高。
90 秒没思路，蒙一个，走 —— 不再看第二眼。
:::

## 二、考点分布

### 高频集群（合计占比超 60%）

| 题型 | 特征 | 难度 |
|---|---|---|
| 基础应用题 | 列方程求解，最常见 | 易—中 |
| 工程问题 | 赋值法秒解 | 易 |
| 行程问题 | 相遇、追及、流水行船 | 中 |
| 经济利润 | 折扣、分段计费 | 易—中 |
| 排列组合 | 分类分步、捆绑插空 | 中—难 |
| 概率问题 | 古典概型为主 | 中 |
| 几何问题 | 面积体积、勾股定理 | 易—中 |

### 稳定出现的小题型

| 题型 | 说明 |
|---|---|
| 年龄问题 | **连续多年稳定出现**，核心是"年龄差不变" |
| 星期日期 | **连续多年稳定出现**，靠周期和余数 |
| 容斥问题 | **连续多年均有考查**，记住公式即可 |
| 数列问题 | 偶有出现 |
| 最值问题 | 和定最值、最不利原则 |

::: tip 从备考顺序看
**先学工程、利润、容斥、基础方程** —— 这四类方法固定、计算量小，是最容易拿分的。
**年龄、星期日期** 也属于"知道方法就能做"，成本很低，值得学。
**排列组合、概率** 中等投入。
**复杂行程、多动点几何** 直接放弃。
:::

## 三、难度分布与决策

数量关系的难度大致呈 **"5:3:2"** 结构：约一半是基础题，三成中等，两成难题。

<GkChart name="sl-difficulty" />

对应的处置动作：

- **基础题（约一半）** → 用赋值法、方程法直接做
- **中等题（约三成）** → 30 秒能看出路径就做，看不出就走
- **难题（约两成）** → **直接放弃，蒙**

### 30 秒决策法则

> **读题后 30 秒内无法明确解题路径，或预估计算步骤超过 4 步，立即标记跳过。**

::: warning 这个法则必须练成条件反射
考场上最大的时间黑洞就是数量关系：一道题想 3 分钟，做对了，但代价是后面 3 道资料分析没时间做。
**一道数量题换三道资料题，这笔账怎么算都亏。**
:::

## 四、可以放弃的题型

| 类型 | 特征 |
|---|---|
| 复杂排列组合 | 元素超过 3 个、需要分类讨论多层 |
| 多未知数应用题 | 需要列 3 个以上方程 |
| 复杂几何 | 多动点、需要构造辅助线 |
| 计算量极大的题 | 预估步骤超过 4 步 |
| 题干超长、信息杂乱 | 读题就要 1 分钟以上 |

::: tip 判断标准很简单
**读完题后，如果你能一句话说出解题方法，就做；说不出来，就不做。**
不要"边做边想"，那是数量关系最容易陷进去的姿势。
:::

## 六、学习路径建议

| 阶段 | 内容 | 目标 |
|---|---|---|
| 第 1 步 | 工程、利润、容斥、基础方程 | 这四类必须 100% 掌握 |
| 第 2 步 | 年龄、星期日期 | 知道方法即可，成本极低 |
| 第 3 步 | 行程基础、几何基础、概率古典 | 掌握基础情形 |
| 第 4 步 | 排列组合基础 | 掌握分类分步与基本模型 |
| 不学 | 复杂排列组合、复杂几何、多未知数 | **直接放弃** |

::: tip 与现有备考进度的衔接
数量关系目前是零进度，且只剩 70 天。
**建议只投 8–10 小时**：先把工程、利润、容斥、基础方程四类学到能用（约 4 小时），再用 4–6 小时刷题巩固。
剩下的时间给资料分析和政治理论——那两块的投入产出比高得多。
:::
