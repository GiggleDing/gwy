# 考场取舍与猜题

这一页是数量关系里**最重要的一页**——因为它决定了你在考场上不会因为这一个模块而崩盘。

## 一、30 秒决策法则

> **读题后 30 秒内无法明确解题路径，或预估计算步骤超过 4 步，立即标记跳过。**

### 决策流程

```
读到题
  │
  ├─ 30 秒内能说出解题方法？ ── 能 ──→ 做，90 秒为上限
  │
  └─ 不能 ──→ 蒙一个，标记，走人，不回头
```

::: danger 考场上最贵的三个动作
1. **"我再想想"** —— 想 2 分钟，做对了，代价是后面 2 道资料分析没做
2. **"先列个方程试试"** —— 列出来了，解不出来，时间没了
3. **"回头再检查一下"** —— 数量关系的回头成本最高，且改对的概率远低于改错

**这三个动作一个都不要做。**
:::

## 二、做哪几道

按优先级手动挑：

| 优先级 | 题型 | 理由 |
|---|---|---|
| 1 | 工程问题 | 赋值法固定，30 秒出思路 |
| 2 | 经济利润 | 公式直接，计算量小 |
| 3 | 容斥问题 | 背公式就有答案 |
| 4 | 基础方程题 | 题干简单，一个未知数 |
| 5 | 年龄 / 星期日期 | 知道方法就能做 |
| — | 其余 | 全部蒙 |

::: tip 目标定在"做 3–5 题"
**15 题里，挑出 3–5 道最顺手的做对，其余统一蒙。**
期望得分 ≈ 4（做对）+ 2.5（蒙对 10 题中的 1/4）= 6.5 题的分值。
这个成绩已经超过了绝大多数"全蒙"或"死磕 3 道"的考生。
:::

## 三、猜题技巧

::: warning 先说清楚一件事
下面这些技巧**没有可靠的统计证据**，它们的价值是**避免你在慌乱中做出更差的决策**，不是真的能提高命中率。
**不要在研究猜题技巧上花时间。**
:::

### 可用的排除法

| 方法 | 说明 |
|---|---|
| **代入验证** | 选项是具体数值时，直接代入题干验证 |
| **奇偶性** | 两数之和为奇数 → 一奇一偶 |
| **整除性** | 答案必须能被某数整除 → 筛掉不满足的选项 |
| **量级判断** | 先估数量级，筛掉差一个数量级的选项 |
| **范围判断** | 答案一定在某区间内 → 排除区间外的 |

### 常见的排除信号（弱证据）

| 信号 | 说明 |
|---|---|
| 选项含 0 或 1 | 通常不是答案（但不绝对） |
| 问"最多" | 倾向选第二大的 |
| 问"最少" | 倾向选第二小的 |
| 选项分布均匀 | 保持其中一个选项不变 |

::: danger 最重要的纪律：统一蒙一个
**剩余的题全部蒙同一个选项（比如全蒙 B）。**

不要"这题我觉得像 A、那题像 C" —— 分散蒙的期望值不会更高，但方差会更大，更容易出现"全军覆没"。
统一蒙一个，命中率稳定收敛在 25%。
:::

## 四、数量关系的时间怎么来

数量关系只能做 6 分钟，意味着**必须从别的地方省出时间**。

| 来源 | 能省多少 |
|---|---|
| 资料分析不超时（每篇 ≤ 7 分钟） | 4–6 分钟 |
| 政治理论控制在 13 分钟内 | 2–3 分钟 |
| 常识判断 30 秒一题不回头 | 2–3 分钟 |
| 判断推理图形题不恋战 | 3–4 分钟 |

::: tip 核心逻辑
**数量关系的时间不是"想出来"的，是"从别的模块省出来"的。**
如果前面的模块都超时，数量关系就只能全蒙——这是必然结果，不是意外。
:::

## 五、答题顺序上的位置

| 方案 | 顺序 | 适用 |
|---|---|---|
| 推荐 | …… → 言语 → **数量（最后）** | 数量零基础 |
| 备选 | 政治 → 常识 → **数量** → 资料 → 判断 → 言语 | 数量有基础，想趁清醒时做 |

::: warning 不推荐把数量放中间
除非你数量已经能稳定做对 8 题以上，否则**不要把它放在中间**。
放中间的最大风险是：做不顺时心态崩掉，影响后面几个大模块。
**放最后，做多少算多少，心理压力最小。**
:::

## 六、每次模考记什么

| 指标 | 含义 |
|---|---|
| 实际用时 | 对比 6 分钟的预算 |
| 做了几题 | 是否控制在 3–5 题 |
| 做对几题 | 做的那几题的准确率 |
| 超时几题 | 超过 90 秒的题数（**应为 0**） |

::: danger 一条红线
**模考里数量关系超时的题数必须是 0。**
做不到就说明 30 秒决策法则没练成——这是需要专门练的动作，比做题本身更重要。
:::

## 七、一句话总结

> 数量关系不是用来"做完"的，是用来**"在 6 分钟里捡到几分"**的。
> 把止损线练成肌肉记忆，这个模块就不会成为你的灾难。
